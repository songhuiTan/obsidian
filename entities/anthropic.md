# Anthropic

## 概述

Anthropic 是美国领先的AI研究公司，以 Claude 系列模型闻名。其旗舰模型 Claude Opus 4.6 截至2026年3月以 Elo 1503 分位居全球顶尖模型之首，仅以2.7%的优势领先中国顶尖模型。^[raw/articles/stanford-2026-ai-index-report.md]

## 与知识库的关系

Anthropic 的 Claude 技术与本知识库关注的 [[claude-code]] 工具直接相关。Claude Code 是 Anthropic 推出的 AI 编程 CLI 工具，在本知识库的多篇技能文档中被提及。

## 行业地位

- 与 OpenAI 并称 AI 领域两大巨头
- 累计融资据福布斯AI 50榜单统计达千亿美元级别
- 其模型是 [[知识蒸馏]] 中被广泛使用的"教师模型"之一
