# OpenClaw

## 概述

OpenClaw 是一个开源 AI Agent 框架，以"养龙虾"为社区文化符号。用户通过安装 Skill（技能包）来扩展 Agent 能力，形成一个生态系统。

## 核心特性

- **24小时在线** — 持久运行，跨平台支持
- **Skill 生态** — 通过安装 SKILL.md 技能包扩展能力
- **持久记忆** — 跨会话上下文保持
- **任务管理** — Agent 自主规划和执行任务
- **多平台支持** — 可在本地或云端部署

## 角色定位

OpenClaw 在开发工作流中扮演"项目经理"角色：
- 需求分析 → 写 PRD + 技术方案 → 用户确认 → 协调执行工具 → 交付结果
- 与 [[claude-code]]（高级开发者角色）形成互补工作流

## 社区生态

- **官方资源**：docs.openclaw.ai / GitHub: github.com/openclaw/openclaw
- **技能市场**：ClawHub + skills.sh
