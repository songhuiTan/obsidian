SafeLine（雷池）—— 开源自部署 WAF（Web 应用防火墙），21.7K Star。把公网入口常见的防护能力做成普通开发者也能部署和配置的形态。

## 核心定位

放在业务前面的反向代理。外部请求先经过 SafeLine，判断是否有风险，再决定放行、拦截、限速或人机验证。

不替代业务层安全（代码安全、权限设计、依赖升级、备份恢复），但**有入口防护和裸奔上公网，体验差别很大**。

## 防护能力

### CC 防护（频率限制）
- 对访问过快、请求节奏异常的来源进行限制
- **等候室**能力：流量高峰或疑似 CC 攻击时，请求按策略排队、等待、放行，后端不用一次性接住所有请求
- 适合没有复杂弹性扩容的小团队

### Bot 防护（人机验证）
- 综合分析：源 IP 恶意行为历史、客户端是否为真实浏览器、是否存在监控/调试行为、键盘鼠标行为是否符合人类习惯
- 对真人尽量放行，对自动化程序增加成本

### 动态防护
- 每次访问动态处理 HTML 和 JS 代码
- 防止爬虫和自动化工具依赖稳定结构反复抓取
- 包含请求防重放能力，降低请求被捕获后反复利用的风险

### 身份认证
- 在应用前加一层访问验证（适合测试环境、临时后台、内部工具误暴露公网）
- 支持钉钉、企业微信、GitHub 等统一认证

### 其他
- SQL 注入、XSS、命令注入、SSRF、路径穿越、RCE、暴力破解、HTTP Flood、漏洞扫描等

## 部署

```bash
bash -c "$(curl -fsSLk https://waf-ce.chaitin.cn/release/latest/manager.sh)"
```

流程：
1. 进入控制台，初始化账号
2. 添加需要保护的应用（博客、后台、API 等）
3. 把域名或反向代理入口指向 SafeLine
4. 按需开启防护
5. 查看攻击事件、访问日志、统计报表，调整策略
