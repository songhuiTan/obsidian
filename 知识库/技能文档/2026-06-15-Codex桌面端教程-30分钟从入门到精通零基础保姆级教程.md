## 视频概要

一个保姆级零基础 Codex 桌面端使用教程，详细介绍了 Codex 的安装、核心功能（项目/对话、权限模式、模型选择、思考强度）、插件生态、技能系统、自动化任务、工作树模式、AGENTS.md 配置等。

## 关键要点

- **Codex vs ChatGPT**：ChatGPT 只能给建议不动手，Codex 是 AI Agent——能自己创建文件、运行程序、上网、操作浏览器，甚至部署上线
- **四种使用方式**：CLI、VS Code 插件、桌面客户端、网页版——桌面端对新手最友好
- **登录方式**：ChatGPT 账号登录（推荐，额度共用）vs API Key 登录（按量计费）
- **核心概念**：
  - **项目**：对应电脑上的文件夹，所有生成文件保存在此
  - **对话**：项目下的工作线程，一个对话处理一个任务
  - **权限模式**：默认权限（安全）→ 自动审查 → 完全访问（高效但有风险）
  - **模型选择**：o4-pro（最强）> o4-mini > o3（快速省钱）
  - **思考强度**：低/中/高/超高——控制 AI 的推理深度
- **插件 vs 技能**：技能 = 执行步骤说明书；插件 = 技能集 + 外部应用连接
- **自动化任务**：自然语言创建定时任务，但建议先在普通对话试跑确认
- **工作树模式**：创建独立副本修改，不碰原始文件，解决多任务冲突
- **操作浏览器/电脑**：Codex 能自主打开浏览器访问网站、操作电脑上的应用
- **AGENTS.md**：项目级规则文件（≤150行），每次对话自动读取
- **六大最佳实践**：
  1. 设计文件用项目，不要用对话
  2. 一个任务一个对话
  3. 复杂任务先让出计划再动手
  4. 写清楚完成标准
  5. 经常提交
  6. 让 Codex 审查 Codex 的代码
