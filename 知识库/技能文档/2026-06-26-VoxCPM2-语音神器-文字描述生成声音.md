# VoxCPM2 — 写句话就能克隆任意音色，方言也支持！

## 概述

OpenBMB（面壁智能 + 清华实验室）2026 年 4 月开源的 TTS 模型。**2B 参数，Apache 2.0 协议**，200 万小时多语种语音数据训练。最独特的卖点是 **Voice Design**——不用录参考音频，写一段文字描述就能生成新声音。同时支持可控声音克隆、高保真克隆、30 种语言和 9 种汉语方言，消费级显卡（8GB VRAM）即可实时推理。

## 核心亮点

### Voice Design：文字描述捏声音

这是 VoxCPM2 最独特的功能——不需要参考音频，用自然语言描述你想要的声音，模型直接生成。ElevenLabs 的 Voice Design 是付费功能，VoxCPM2 免费。

```python
wav = model.generate(
    text="(一位年轻女性，声音温柔甜美)你好，欢迎使用VoxCPM2！",
    cfg_value=2.0,
    inference_timesteps=10,
)
```

性别、年龄、音色、情绪、语速、口音，都能控制。InstructTTSEval 评测上，中文三项指标和 Qwen3TTS 并列第一，英文三项压过 Hume 和 Mimo-Audio。

### 可控声音克隆：音色与风格解耦

传统声音克隆是音色和风格一起复制。VoxCPM2 把两件事拆开——**音色从参考音频提取，风格用文字指令单独控制**。

```python
wav = model.generate(
    text="(语速稍快，语气欢快)这是带风格控制的克隆声音。",
    reference_wav_path="speaker.wav",
    cfg_value=2.0,
    inference_timesteps=10,
)
```

### 高保真克隆（Ultimate Cloning）

需要参考音频 + 准确文本转录。模型用文本来对齐音频，完整复刻说话人的音色、节奏、情绪和停顿。与可控克隆的区别：高保真模式不允许文字控风格，追求一模一样。

### 三种模式对比

| 模式 | 参考音频 | 文本转录 | 风格控制 | 适用场景 |
|------|---------|---------|---------|---------|
| Voice Design | 不需要 | 不需要 | 文字描述 | 完全创生新声音 |
| Controllable Cloning | 需要 | 不需要 | 文字指令 | 保留音色+换语气 |
| Ultimate Cloning | 需要 | 需要 | 无（全复制） | 精确复刻 |

## 架构原理

**关键设计**：不走离散 token 路线。主流 TTS 将语音切成离散 token，再以语言模型预测 + 声码器合成。VoxCPM 直接在连续空间做扩散自回归生成。

**四阶段流水线**：

```
Local Encoder → Text-Semantic LM → Residual Acoustic LM → Local DiT → AudioVAE V2 → 48kHz 波形
```

- **底层语言模型**：MiniCPM-4
- **扩散部分**：借鉴 DiTAR
- **流匹配**：参考 CosyVoice
- **AudioVAE**：骨架来自 DAC，非对称编解码：输入 16kHz 参考音频 → 直接输出 48kHz

**核心优势**：不压成离散编码，保留连续表示一路生成到底。声音细节、韵律、感情变化保住了，不会出现"听得出是合成但说不上哪不对"的塑料感。

## 安装 & 使用

```bash
pip install voxcpm
```

三行代码出声音：

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)
wav = model.generate(
    text="VoxCPM2 是目前推荐的多语言语音合成版本。",
    cfg_value=2.0,
    inference_timesteps=10,
)
sf.write("demo.wav", wav, model.tts_model.sample_rate)
```

国内网络慢可从 ModelScope 下载：

```python
from modelscope import snapshot_download
snapshot_download("OpenBMB/VoxCPM2", local_dir='./pretrained_models/VoxCPM2')
```

CLI 模式：

```bash
voxcpm design --text "你好世界" --output out.wav
voxcpm clone --text "这是克隆的声音。" --reference-audio voice.wav --output out.wav
```

WebUI 启动（源码目录下）：

```bash
python app.py   # 浏览器打开 localhost:8808
```

## 关键洞察

- **Voice Design 是差异化杀手功能**：开源 TTS 里独一份。不需要录参考音频，自然语言描述即可捏声音，大大降低 TTS 使用门槛。ElevenLabs 的类似功能要付费，VoxCPM2 免费且 Apache 2.0。
- **连续空间 > 离散 token**：不走离散 token 路线的架构选择，保留了语音的连续细节。四阶段流水线（Local Encoder → 语义 LM → 声学 LM → DiT）是当前 TTS 的前沿设计方向。
- **商业友好**：Apache 2.0 协议，可商用。播客配音、视频旁白、语音助手、有声书都适用。
- **仍在完善中**：Voice Design 不是每次都稳定出理想效果，可能需要多次生成。论文自己也承认了这一点。
- **生态扩张快**：社区衍生项目丰富（GGUF、ONNX、ANE、ComfyUI、Rust），说明架构设计良好，底层模型本身有吸引力。
- **与既有工具链的潜在整合**：VoxCPM2 的 pip install + Python API 使其容易集成到现有的 Hermes TTS 能力中（配合 text_to_speech 工具或音频生成工作流）。48kHz 输出质量足够作为有声书、播客配音的生产级方案。
