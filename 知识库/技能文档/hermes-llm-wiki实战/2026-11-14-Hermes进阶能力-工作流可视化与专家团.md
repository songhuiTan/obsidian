# 10分钟给Hermes手搓进阶能力：工作流可视化+专家团模式+Hermes手机端 | Claude Code + MiniMax M3的coding实战

> 来源：飞书文档（李君陌AI笔记）｜Hermes & OpenClaw 实战进阶配套笔记 第10篇

> `heart`
> 今天我们来给大家分享一下，新手也能用vibe coding来给自己的Hermes做工具，首先我给他做了一个专家团的模式，当我提出一个问题的时候，可以由我的多个Agent同事来跟我进行思考和解答，而且还可以把他们拉到同一个工作空间里边作为一个项目来进行工作，然后呢，我还给他做了一个Agent工作流设计器，可以把你所有意向的作为一个工作流节点编排进来去完成特定的任务，可以让特别复杂的长任务也能进行比较可控的编辑，另外Hermes一直缺一个比较好的应用端，所以呢，我还给他做了一个比较好用的移动端，能看到你所有的hermes员工以及专家团，可以在你的工作空间里进行交互，还可以监控你的办公室和Agent员工的状态，而以上这些基本都是靠vibe coding就都能做到的，而我采用的组合是claude code + MiniMax M3，既有性价比，而且token效率和做出的效果也是非常不错。
> 而且MiniMax M3原生多模态的能力非常适合在有参考图的情况下来做前端，只需提供一张设计图，就能做出几乎非常接近原图的APP，还带了完整的交互。你甚至可以只给他一张手绘草稿图，也能给你做出一个非常不错的APP。接下来呢我们看一下如何来使用这个组合。
