# OpenCLI - 浏览器桥接多平台命令行工具

## 核心概念

OpenCLI 是一个开源命令行工具（GitHub 7.3k ⭐），通过连接本地 Chrome 浏览器，复用已登录的会话状态，将任何网站变成终端可操作的命令。

- 项目地址: https://github.com/jackwener/opencli
- 龙虾技能包: https://github.com/joeseesun/opencli-skill
- 支持 44 个平台，244 个命令

## 工作原理

不走 API，不申请资质。直接连接本地已打开的 Chrome 浏览器，复用浏览器中已登录的会话状态。你能在浏览器里操作的平台，OpenCLI 就能操作。

## 安装条件

1. 龙虾必须部署在本地电脑（非云端）
2. 安装 Skill: `安装 https://github.com/joeseesun/opencli-skill`
3. 安装 Chrome 扩展: OpenCLI Browser Bridge（Chrome 与 OpenCLI 之间的桥梁）
4. 目标平台需先在 Chrome 中登录好账号
5. 默认浏览器必须是 Chrome

## 支持的功能分类

### 1. 热门/排行类
```bash
opencli zhihu hot          # 知乎热榜
opencli bilibili hot       # B站热门视频
opencli weibo hot          # 微博热搜
opencli twitter trending   # Twitter热门话题
opencli reddit hot         # Reddit热帖
```

### 2. 搜索类
```bash
opencli bilibili search --keyword "关键词"
opencli zhihu search --keyword "关键词"
opencli xiaohongshu search --keyword "关键词"
opencli reddit search --query "关键词"
```

### 3. 读取/浏览类
```bash
opencli xiaohongshu feed   # 小红书首页推荐
opencli bilibili feed      # B站关注动态
opencli twitter timeline   # Twitter首页时间线
```

### 4. 发布/写操作类
```bash
opencli twitter post --text "内容"    # 发推
opencli twitter reply --id ID --text  # 回复推文
opencli boss batchgreet               # BOSS直聘批量打招呼
```

### 5. 下载类
```bash
opencli bilibili download BV号    # B站视频下载（1080P）
```

### 6. 桌面应用控制类
- ChatGPT 桌面版控制
- Codex 桌面版控制
- 微信、飞书控制
- ⚠️ 仅支持 macOS，不支持 Windows

## 限制

- 桌面应用控制仅 macOS
- 部分命令不支持 Windows
- 需要本地部署，云部署不可用
- 依赖 Chrome 浏览器
