# Penpot — 5万 Star 开源设计平台，AI 直接读懂设计稿

> 来源：逛逛GitHub（逛逛）｜微信公众号 · 2026-06-26
> 原文：[GitHub上 5 万 Star，这个开源设计平台让 AI 直接读懂设计稿。](https://mp.weixin.qq.com/s/5lvuygc9DOX4rXNTu1eP1g)
> 项目地址：[penpot/penpot](https://github.com/penpot/penpot) | ⭐ 5万+ Star

## 概述

Penpot 是一个开源的设计协作平台——UI 设计、原型制作、团队协作全在浏览器里搞定，GitHub 5 万+ Star，全球 150 万用户，已迭代 5 年。由西班牙开源公司 Kaleidos（前作 Taiga）开发。

核心定位是 **"唯一真正部署无关的设计平台"**——既可直接使用官方云端服务，也可 Docker 自部署，设计文件、组件库、Design Tokens 全在本地。对金融、政府、医疗等对数据合规有要求的行业，内网部署是刚需。

最独特的价值在于 **AI 时代的设计资产可编程性**：内置 MCP（Model Context Protocol），AI Agent 可以直接读取设计文件中的真实 components、tokens、layers、页面结构，而非一张截图。

## 核心亮点

### 设计即代码（Design as Code）

Penpot 的设计哲学：**设计文件本身就是代码**。不是导出时翻译成代码，而是从底层就用 SVG、CSS、HTML 这些 Web 标准来表达设计。

| 能力 | 说明 |
|------|------|
| Inspect 模式 | 选中任何元素，直接看到可复制的 SVG/CSS/HTML 代码 |
| 原生 CSS Grid & Flex | 画响应式布局，按 Grid/Flex 规则渲染，所见即所得 |
| 开放标准 | 文件用开放标准保存，其他软件也能打开，不锁定数据 |

### W3C Design Tokens 标准

Penpot 是 **业内第一个完整支持 W3C Design Tokens 标准的设计工具**。颜色、字号、间距等设计变量统一管理，设计稿改一处全项目联动，开发端也用同一套变量，不需要手动同步。对建设计系统的团队来说，这是刚需。

### MCP（Model Context Protocol）

Penpot 内置了 MCP 协议支持。AI Agent（如 Claude Code）连接 Penpot 后：

- 直接读取设计文件中的 **components、tokens、layers、页面结构**
- 按需生成或调整组件
- 代码改动能同步回设计稿

**关键不同**：AI 读到的是真实的结构化设计数据，不是一张截图。这让 AI 生成 UI 不再需要靠猜。

### 自部署能力

```bash
# 下载官方 docker-compose 配置
curl -o docker-compose.yaml https://raw.githubusercontent.com/penpot/penpot/main/docker/images/docker-compose.yaml

# 启动
docker compose -p penpot -f docker-compose.yaml up -d
```

跑起来后访问 `http://你的服务器IP:9001`。支持 HTTPS、反向代理、子路径部署。

### 项目背景

- **公司**：Kaleidos（西班牙），开源软件公司
- **创始人**：Pablo（之前做过 Taiga——开源项目管理工具，全球十几万用户）
- **起源**：团队招了设计师后发现开源设计工具基本没有好用的，于是自己做了
- **迭代**：已坚持 5 年，不是玩具项目

## 关键洞察

- **AI 时代的设计平台新范式**：Penpot 内置 MCP 让 AI Agent 直接读取结构化设计数据，这比截图→AI 猜 UI 的方案精确得多。结合 Claude Code 等 AI Coding 工具，可以实现"设计→代码"的完整闭环。
- **"设计即代码"的哲学意义**：用 SVG/CSS/HTML 而非专有格式，意味着设计文件天然可被 AI 解析、可版本管理、可互操作。这与 Figma 的专有格式形成根本差异。
- **Design Tokens 是设计系统的基石**：完整支持 W3C 标准，让设计资产可编程、可版本化。对于需要建设 Design System 的团队，这是 Figma 之外一个完全开源的替代选项。
- **自部署的设计工具是空白市场**：Figma 被 Adobe 收购后，很多对数据合规有要求的企业在寻找替代品。Penpot 的 Docker 自部署能力精准覆盖了这个空白。
