# resume-template：不会 LaTeX，也能整一份干净简历 PDF

## 简介

GitHub 项目 **celiobjunior/resume-template**（1.3k star），用 LaTeX 做专业干净的简历模板，但不需要懂 LaTeX。

## 使用方式

搭配 OpenAI Prism 编辑器：把 `resumes/en/resume.tex` 代码复制到 Prism，让 AI 帮你改姓名、经历、项目描述，直接下载 PDF。

## 亮点

- `/prompts/` 文件夹：专门帮你把工作经历 bullet points 写成更像简历语言
- FAQ 提醒：不建议在技术和国际岗位简历里放照片（可能影响 ATS 自动筛选）
- LaTeX 排版比 Word 更规整：对齐不歪、分页不炸、PDF 字体不变形
