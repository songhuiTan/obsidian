> 来源：飞书云文档（作者：会飞的蜗牛）

> 归档方式：飞书 Open API 读取文档块 + clientvars 接口提取多维表格字段配置 + PyInstaller 逆向解包 EXE 提取全部内置提示词

![工具主界面](../assets/2026-09-19-薛辉爆款文案工具/img_001_工具主界面.png)

## 概述

一套基于**薛辉（薛辉小清新）爆款文案方法论**打造的抖音口播文案生成工具，免费发放，有两个形态：

1. **飞书多维表格智能体**（主推）：复制模板到自己飞书账号 → 填行业赛道 → 点字段"更新"按钮 → AI 自动生成标题/钩子/口播文案。底层用飞书 AI 字段扩展（DeepSeek-V3.1，非深度思考模式），零配置可用。
2. **Windows 桌面 EXE**（短视频文案创作工具.exe，18.4MB）：PyInstaller 打包的 Python 3.11 + pywebview 应用，12 个功能页，用户自配 API Key（DeepSeek/OpenAI兼容/通义/GLM/Kimi/MiniMax），全部提示词内置在前端 JS 里。

核心资产不是工具本身，而是**薛辉方法论的结构化知识库**：八大爆款情绪元素、8 套选题模板、30+ 爆款选题元素（含 20 个两两组合公式）、30 种钩子、17 种文案类型、4 大内容体裁——全部被编码成了下拉选项和提示词。

## 产品结构：两个形态的架构拆解

### 形态一：飞书多维表格智能体

表格「爆款生成工作流」共 11 个字段，构成一条人机协作流水线：

| 字段 | 类型 | 作用 |
|------|------|------|
| 行业赛道 | 文本（手填） | 人设、行业、产品、目标用户画像 |
| 爆款选题元素 | 单选（32 选项） | 选择爆款元素组合 |
| 标题生成 | AI 字段 | 一键生成 10 个标题 |
| 复制一个标题 | 文本（手填） | 从生成结果中挑一条粘贴 |
| 勾子选择 | 单选（30 选项） | 选择钩子类型 |
| 勾子生成 | AI 字段 | 一键生成 10 个钩子 |
| 复制一个钩子 | 文本（手填） | 挑一条粘贴 |
| 拍摄风格 | 文本（手填） | 抖音风、口播感、干货感等 |
| 文案类型 | 单选（17 选项） | 口播文案的结构类型 |
| 口播文案生成 | AI 字段 | 生成 2 条完整可直接拍摄的文案 |
| 标题生成.思考过程 | 系统字段 | AI 字段的思考过程记录 |

工作流：**填行业 → 选元素 → 生成标题 → 挑标题 → 选钩子 → 生成钩子 → 挑钩子 → 填风格/类型 → 生成完整文案**。每步"生成-挑选"分离，人保留选择权，AI 只负责批量产出。

### 形态二：Windows EXE 桌面工具

PyInstaller 打包，全部业务逻辑在 532KB 的 `app.html` 内嵌 JS 中。LLM 调用是标准的 OpenAI 兼容 `chat/completions`（Bearer Key，temperature 0.7，max_tokens 4096，60s 超时），配置持久化在本地 HTTP 服务的 `/api/config`。

12 个功能页：

| 页面 | 输入 | 输出 |
|------|------|------|
| 爆款选题 | 行业人设 + 主脚本/分脚本 + 爆款元素 | 10 个选题（JSON） |
| 成交选题 | 行业人设 + 主/分脚本 + 进店/成交理由（15 项多选） | 10 个高变现选题 |
| 痛点选题 | 行业背景 + 目标客户 | 50 条痛点问句 |
| 脚本创作 | 选题描述 + 人设 + 其他要求 | 逐字稿 + 分镜头脚本 |
| 文案二创 | 原文案 | 过原创审核的二创文案 |
| 爆款拆解 | 短视频链接 | 内容类型/爆款元素/目标人群/置景呈现分析 |
| 文案洗稿 | 原文案 | 大白话改写版 |
| 爆款仿写 | 爆款文案 + 人设 + 字数 | 3-5 个去重版本 |
| 自选选题 | 话题描述 + 内容方向 | 6 个选题方案（含元素/模板/体裁标注） |
| 热门话题 | 行业领域（12 类） | 热门话题推荐（注：实为 LLM 凭训练数据生成，非实时联网） |
| 黄金开头 | 视频主题 + 开头风格（8 型多选）+ 数量 | 3-8 个前 3 秒开头 |
| 分镜脚本 | 文字脚本 + 分镜数（1-20）+ 视频风格（6 类） | 专业分镜表（JSON） |

头牌揭秘+成本、最差体验+然后（逆转）、怀旧+反差（今昔对比）、荷尔蒙+猎奇（禁忌关系）、人群+最差（精准攻击）、头牌+然后（跌落神坛）、猎奇+成本（低成本猎奇）、反差+荷尔蒙（身份与欲望的错位）、怀旧+成本（情感价值成本）、然后+人群（群体逆袭）、最差+猎奇（底线挑战）、头牌+荷尔蒙（魅力权威）、反差+然后（行为结果悖论）、成本+然后（投资回报叙事）、人群+怀旧（代际符号）、猎奇+然后（都市传奇）、最差+头牌（巅峰与深渊）、荷尔蒙+成本（情感算计）、然后+怀旧（时光机效应）、人群+反差（圈层撕裂）

### 8 套选题模板（EXE 自选选题页内置）

1. 痛点直击：大众普遍烦恼 + 解决方案（戳痛→讲危害→给方法）
2. 结果前置：最终效果放开头 + 实现路径
3. 正反反差/认知差：大众认知 + 颠覆结论
4. 数字清单：数字 + 干货/避坑/步骤
5. 人群细分：精准人群 + 专属问题
6. 场景绑定：场景 + 当下难题
7. 避雷避坑：XX 千万别做、90% 的人踩过的坑
8. 悬念反问：提问勾起好奇

### 4 大主脚本 × 15 分脚本（内容体裁树）

- **教知识**：推荐型（美好愿景/圈定人群/引发好奇）、解题型（场景难题/低行动成本/具体操作）、案例型（案例描述/知识点总结/应用方法）、揭秘型（提出揭秘事件/讲述内情/避免方法）
- **晒过程**：过程展示（进货筹备/咨询成交/技术服务/售后）、测评产品（对比/极限/化验测评）、任务挑战（高低成本/限时间地点）、事件体验（新奇体验/奇葩规则/角色互换）

- **讲故事**：小有成就、成功案例、平凡英雄、苦难经历、重走成功路（各有三段式结构）

**1. 爆款选题（buildPrompt）：**

**2. 成交选题（buildPrompt2）：**
> 你是一个专业的短视频高变现选题专家。……用户信息含"选择的进店/成交理由"（多选拼接），要求内容更具转化性。其余结构同上，输出 10 个高变现选题。

**3. 脚本创作（buildPrompt3）：**
> 你是一个专业的短视频脚本创作专家。请生成一篇符合短视频传播逻辑的文案逐字稿和详细的拍摄分镜头脚本。

> 逐字稿必须包含：爆款开头（吸引注意力的开场白）→ 核心内容（逻辑清晰）→ 结尾金句（有力量、便于传播）。
> 分镜头每个包含：镜头序号、景别（全景/中景/近景/特写）、画面内容描述、对应文案/台词、时长建议。

**4. 文案二创（buildPrompt4）：**
> 你是一个专业的短视频文案二创专家。请将以下原文案重新创作成一篇全新的、可以通过原创审核的文案。

**5. 爆款拆解（buildPrompt5）：**
> 你是一个专业的短视频爆款拆解分析专家。请根据用户提供的短视频链接{videoLink}，对这个爆款视频进行深度拆解分析。
>
> 输出 JSON：{contentType（讲故事/教知识/晒过程/聊观点/产品介绍/其他）, viralElements（爆款元素详细分析：开头钩子、情绪调动、节奏把控）, targetAudience（意向人群：年龄性别兴趣需求）, presentationStyle（置景和呈现方式：场景设置、拍摄手法、视觉呈现）}

**6. 文案洗稿（buildPrompt6）：**
> 你是一个专业的短视频文案洗稿专家。请将以下原文案改写成全新的文案，要求：
> ①改话术，不与原文案一样；②同一个意思，核心主旨不变；③大白话、像朋友聊天；④形容词改动词，更生动；⑤避开专业术语，口语化；⑥避开抖音最新违规词敏感词；⑦不要太官方，要接地气；⑧祛除AI味，避免生硬表达；⑨原文完全改但意思不改；⑩改完可复制。直接输出，不要说明文字。

**7. 痛点选题（buildPrompt7）：**
> 你是一个专业的短视频内容策划专家。请根据行业背景{industryBackground}和目标客户{targetCustomer}，生成50条口语化问句形式的痛点问题，用于抖音内容选题。
>
> 要求：问号结尾；像朋友聊天；基于真实需求；引起共鸣思考；每条不超20字；激发好奇心；符合抖音特点；每行一条不加编号；真实可信反映实际困扰。

**8. 爆款仿写/去重（buildPrompt8）：**
> 你是一个专业的短视频文案创作专家。请对用户提供的爆款文案进行去重处理，保持原汁原味。〔若有字数要求：强调必须严格按用户指定字数，绝对不要默认生成800字〕

> 你是一位专业的短视频选题策划专家，精通薛辉（薛辉小清新）的选题方法论。请根据话题描述和内容方向，运用薛辉选题方法论生成6个优质选题方案。

> 【薛辉选题方法论核心框架】
> 一、八大爆款情绪元素（万能词根）：成本、人群、猎奇、反差、最差、头牌、怀旧、荷尔蒙（详见上文表格）
> 二、8套选题模板：痛点直击、结果前置、正反反差/认知差、数字清单、人群细分、场景绑定、避雷避坑、悬念反问

**10. 黄金开头（内联 prompt）：**

## 逆向过程记录（技术侧）

1. 飞书 Open API（tenant_access_token）读取文档块 → 193 blocks，含 2 个表格、1 个附件、1 个多维表格嵌入视图
2. 附件 `短视频文案创作工具.zip`（18.4MB）经 drive/v1/medias 接口下载 → 内含单个 Windows EXE
3. EXE 为 PyInstaller (Python 3.11) 打包：手工解析 CArchive TOC（213 条目）→ 提取 `main`（marshal code object）与 `app.html`（532KB）
4. `main` 反序列化确认只是启动器（本地 HTTP 服务 + pywebview 窗口）；全部业务逻辑在 app.html 内嵌 JS
5. app.html 分析：12 页导航、11 条 buildPrompt 函数、callLLM（OpenAI 兼容 chat/completions）、API 配置存储于 %LOCALAPPDATA%/ShortVideoCreator/config.json
6. 多维表格：匿名会话 clientvars 接口（gzip+base64 编码）→ fieldMap 提取 11 字段、AI 字段扩展配置中的 3 条 promptEdit 提示词（DeepSeek-V3.1 扩展，extensionId replit_3051aa9ff1af63e4）

## 关键洞察

- **提示词极简 vs 方法论极重**：EXE 里的提示词都很短（百余字），但把复杂度全部前置到了选项库——用户选"猎奇+成本"而不是写"帮我写猎奇又便宜的选题"。这是"提示词工程让位于知识工程"的典型案例。
- **生成-挑选分离**：多维表格的"生成10条→人挑1条→再生成"循环，是低成本人机协作的稳定模式，比一步到位生成质量更可控。
- **方法论即产品**：薛辉的八大元素/8模板/4体裁体系被完整编码为枚举值，工具只是这套枚举的执行器。提示词可以仿写，但选项库背后是大量账号验证过的经验。
- **两个形态定位不同**：多维表格零门槛（白嫖飞书 AI 字段额度），EXE 灵活性高（自带 Key 不限量）但 Windows-only 且提示词裸奔在前端。
- **"热门话题"页是伪联网**：接口被替换成 LLM 生成，用时会以为是实时的，实际是模型幻觉数据。

## 战略分析

**与现有工具链的对照：**

| 维度 | 薛辉文案工具 | Hermes Agent 体系 |
|------|--------------|-------------------|
| 形态 | 飞书多维表格 AI 字段 + 单机 EXE | 常驻 Agent + 多平台触达（微信端） |
| 提示词资产 | 12 条固定提示词 + 结构化选项库 | Skills 体系（可无限扩展） |
| 方法论沉淀 | 硬编码在前端 JS/字段配置里 | SKILL.md / gbrain 知识库，git 管理 |
| LLM 依赖 | DeepSeek-V3.1（表格）/自配 Key（EXE） | 多 provider 路由（GLM 等） |
| 人机协作 | 生成-挑选循环，人保留决策权 | 全自动 + 幕僚长升级过滤 |

**值得借鉴的点：**

1. **"知识工程 > 提示词工程"的架构**：把领域经验编码成受控枚举（八大元素×8模板×4体裁的组合空间），提示词只做薄薄的执行层。这套思路适用于任何垂直领域 Agent——把小谭正在学的"AI 业务落地四步框架"也这样枚举化，业务方只需点选不需写提示词。
2. **生成-挑选分离的交互模式**：每次批量生成（10标题/10钩子）→ 人工挑 1 条 → 进入下一环节。质量靠人筛而非靠模型自觉，稳定可控。Hermes 的多方案生成场景（如起标题、选题）可以直接套用。
3. **八元素两两组合的选题矩阵**（20 个验证过的组合公式）：内容运营的现成弹药库，配合 InStreet 发帖场景可自动生成选题候选。
4. **轻量逆向验证了供应链**：这类"课程赠品工具"的技术含量 = 提示词 + 选项库 + 壳。方法论的真伪无法从代码验证（"完播率提升300%"等数字无出处），但其结构化程度值得学习。

**风险与判断：**

- 工具本身是"薛辉文案课"的引流赠品（EXE 内嵌作者微信二维码），方法论数字未经独立验证，归档取其结构、不取其断言。
- 多维表格智能体依赖作者方的飞书 AI 字段额度（勾子生成字段已开 AI 付费 trialSource:2），作者停止续费即失效；复制模板到自有账号后需自己承担 AI 字段费用或换成免费额度。
- EXE 仅 Windows，mac 上只能解剖不能运行；但其 app.html 是纯静态页，理论上托管到任意静态服务器 + 自配 API Key 即可用（提示词已全部提取，无技术壁垒）。
