将 Karpathy 的 autoresearch 范式迁移到量化交易领域，基于 Hermes Agent 多 profile 编排实现自主研究循环。首轮复合分 +114%，夏普首次转正。

## autoresearch 核心范式

三个必要条件：
1. **可量化指标** — 没数字就没方向（ML: val_loss，量化: 夏普/Calmar）
2. **可修改配方** — 变更集中在单文件，好审计
3. **可负担成本** — 单次实验成本决定搜索空间

**program.md**：人类编写的研究章程，定义实验规则（改哪些文件、时间上限、评估指标、崩溃恢复、收敛条件）。人类在上面调研究策略，agent 在下面跑实验。一层元优化。

**单文件边界**：所有 diff 在一个文件里，一眼知道 agent 做了什么；固定预算 + 固定评估，不同实验可比。

## 范式迁移到七大领域

| 领域 | 指标 | 单次成本 |
|------|------|----------|
| ML 训练 | 验证损失 | GPU 时间 |
| **量化交易** | **夏普/Calmar** | **回测秒级** |
| 编译器优化 | 运行时间 | 秒级 |
| 云配置优化 | 延迟/成本 | 分钟级 |
| A/B 测试 | 转化率 | 零边际成本 |
| 化学合成 | 产率/纯度 | 实验时间 |
| 硬件设计 | 功耗/面积 | 仿真时间 |

核心新意不在优化算法（底层是贪心局部搜索），在**用 LLM 做"意图→变更"的翻译**——agent 直接读自然语言章程，自己理解并生成代码变更。

## auto-alpha 多 Agent 架构（Hermes 6 Profile）

单 agent 的致命问题：进程崩溃状态全丢、同一模型既提案又决策（自我评估偏差）、跨天运行无法积累知识。

| 维度 | 单 agent | Hermes 多 profile |
|------|---------|------------------|
| 任务持久化 | 进程内存 | Kanban SQLite |
| 调度触发 | 手动 | Cron + context_from |
| 跨会话记忆 | 无 | MEMORY.md + USER.md + FTS5 |
| 知识积累 | 无 | 技能系统 + Curator |
| 角色隔离 | 单一上下文 | 6 独立 profile |
| 自我评估偏差 | 有 | 研究员→评估器→审核员三层 |

**六 profile 交互流：**
1. **Orchestrator** — 调度、分配任务
2. **Researcher A** — GLM-5.1（参数微调）
3. **Researcher B** — Kimi（因子探索）
4. **Evaluator** — DeepSeek（回测验证）
5. **Reviewer** — DeepSeek（独立裁决、签名）
6. **Writer** — 输出报告

### 四个子系统

**技能系统**：agent 解决问题后把流程保存为技能，下次自动加载。渐进式加载 + Curator 后台追踪使用频率。

**Kanban 看板**：SQLite 持久化，父任务完成后子任务自动晋升，评论线程是 agent 间的通信协议。

**Cron + 记忆**：定时触发，context_from 管道上下游注入，FTS5 全文搜索跨会话历史。

**Profile 系统**：6 个独立 Hermes 主目录，不同模型和密钥。

## 首轮实验结果

基线复合分 1.73 → 研究员 A（参数微调 4 次，无法突破）→ 研究员 B（MACD 确认失败、RSI 非对称失败 → ADX 趋势过滤 → **3.70，+114%**），夏普从负值转正。

两个结论：
- **纯微调有天花板** — 配方逻辑不变，调参只是微调
- **新因子有非线性收益** — ADX 与参数优化形成协同

## 自改进循环五层

1. **第一层** — agent 在人类定义的约束内探索（当前状态）
2. **第二层** — 研究员提案 + 评估器回测 + 审核员裁决（已实现）
3. **第三层** — 技能系统固化成功流程（已实现）
4. **第四层** — agent 主动建议修改 program.md，人类退为"批准变更的人"
5. **第五层** — 技能库增长 → 探索效率提升 → 更优策略 → 更多技能固化（几何增益）

## 多 Agent 并行下的方法论优化

审核员应输出**量级分数**而非二选一，后续通过 Contextual Bandit（方向间资源分配）和 Bayesian Optimization（方向内参数调优）优化预算分配。

分步推进：量级分数（现在）→ Bandit（跑几轮后）→ 两层筛选+快速调参（十轮后）→ 概率模型跨轮迁移（远期）。

## 关键洞察

- **约束越多，系统越强**：单文件、固定时间、单一指标——自由在约束之内生长
- **人类退半步，系统进一步**：从执行者变成设计者（设计章程而非调参）
- **知识复利不是比喻**：技能是压缩的经验，让下一次探索从更高起点出发
- **系统比结果重要**：单独实验是事件，持续运行是资产——事件有保质期，资产随时间增值
