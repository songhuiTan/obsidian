## 把 Agnes 接进 Codex

官方也提供了目前市面上流行的各个 agent 工具的接入方法：`agnes-ai.com/doc/overview`

### 第一步：注册账号，拿到 API Key

打开官网 agnes-ai.com，选择「API 平台」注册登录进去。

![API 平台入口](../assets/2026-06-05-Agnes免费API生图生视频/img_010.png)

登录成功后，左侧菜单找到「API 密钥」，点「创建新的密钥」，后面要用。

![创建 API 密钥](../assets/2026-06-05-Agnes免费API生图生视频/img_011.png)

### 第二步：下载并安装 Codex++

这是一个配套的管理工具，配置完成后即可在 Codex 中使用 Agnes 2.0 模型，无需登录 GPT 账号。

下载地址：`github.com/BigPizzaV3/CodexPlusPlus/releases/latest`

![Codex++ 下载页](../assets/2026-06-05-Agnes免费API生图生视频/img_012.png)

根据自己的系统选对应版本，下载完正常安装就行。

### 第三步：配置 Agnes 供应商

打开 Codex++ 管理工具，进左侧菜单 →「供应商配置」→「添加供应商」。

![添加供应商](../assets/2026-06-05-Agnes免费API生图生视频/img_013.png)

按下面信息填：

- **名称**：Agnes
- **接入模式**：纯 API
- **测试模型**：agnes-2.0-flash
- **Base URL**：`https://apihub.agnes-ai.com/v1`
- **Key**：填你刚才复制的 API Key
- **上游协议**：选择 Chat Completions

![配置详情](../assets/2026-06-05-Agnes免费API生图生视频/img_014.png)

填完点「保存」，然后在供应商列表里找到 Agnes，点「使用」：

![选择供应商](../assets/2026-06-05-Agnes免费API生图生视频/img_015.png)

再回到概览页面，点右上角的重启按钮。

![重启](../assets/2026-06-05-Agnes免费API生图生视频/img_016.png)

### 第四步：验证配置是否成功

重启之后，在 Codex 上新建一个会话，随便输一句「你好，请介绍一下你自己」。Codex 正常回复了？那就配成功了。

![验证成功](../assets/2026-06-05-Agnes免费API生图生视频/img_017.png)

整个流程就大概几分钟，还是挺简单的。

## Agnes 的技术底气

直到这个时候我才去扒了一遍 Agnes，时隔半年，又进化了哪些呢？

Agnes 是这次主打的 **Agnes-2.0-Flash**，不只是聊天工具，文生图、文生视频、语音交互、自主浏览网页，都在覆盖范围内。最重要的是，全部 API **免费开放**。

更有意思的是技术路子：Agnes 用的是多模型集群加智能路由架构，把一个任务拆成子任务，分给各自专精的小模型并行处理，推理成本做到了单模型架构的 1/10，速度反而更快。

![多模型集群架构](../assets/2026-06-05-Agnes免费API生图生视频/img_030.png)

这个玩法的思路大概就是：成本本来就低，用免费换开发者生态。这不是促销，是在赌生态。

全球 Top 10 AI Lab，旗下三款模型接连闯入三大国际权威评测——Claw-Eval 真实 Agent 榜、Artificial Analysis 图像编辑榜与视频榜，全部基于真实用户盲评。

## 结语

Token 花费越来越贵这件事，不是今天才开始的。大模型的调用成本一直在涨，很多工具的免费额度越来越少。

Agnes 喊永久免费，我不知道这句话能撑多久。但至少在现在这个时间点，管它那么多，只管用就是。

它不需要替代你的主力工具，主力工具该用就用，该付费就付费。但你的主力工具也有趴窝的时候——就像我的 Codex，因为一个手机号验证就直接给我堵在门外好几天。这种时候，手边有一个能顶上去的备选，是真的有用。
