## 概述

阿里发布全新 Qoder（qoder.com/zh），完成从"程序员 IDE"到"编程 + 通用 Work 双模式 Agent"的转型。作者沉默王二高强度实测一天，结论："Codex 的最佳替代品"。核心变化：BYOK 开放模型接入、Harness 质变、通用模式面向所有人（PPT/视频/日常任务）。

## 核心亮点

### 1. BYOK 升级——不再强绑模型

- 设置 → 模型 → 添加模型，选供应商（如 DeepSeek）+ 模型（DeepSeek-V4-Flash-Vision-Exp）+ 填 API Key → 校验即接入
- 有 BYOK（Bring Your Own Key），Qoder 就是完全开放的 Agent，可爽用任何一家模型，免费的都行

### 2. Harness 大幅提升

- 自主 Agentic 循环更稳定：检索代码库、跨文件编辑、运行测试、根据真实结果自我纠错
- 权限与安全边界更清晰
- 长上下文处理、自动上下文压缩、工具调用准确率明显感知提升

**实测一：鹈鹕骑自行车 SVG**（同 Harness 同提示词对比）
| 模型 | 效果 |
|------|------|
| DeepSeek-V4-Flash-Vision-Exp | 有点抽象，还有很大进步空间 |
| Cantus（新模型，超越「极致」档，擅长超长自主任务执行） | 骑车姿势、脚在脚踏板上的细节都非常到位 |
| Qwen3.8-Max | 嘴里还有鱼，细节惊艳 |

> 作者方法论："模型厉不厉害，跑分看看就得了，真正重要的是同等 Harness、相同提示词环境下实际产出的对比。"

**实测二：Three.js 单文件复刻《暴力摩托》（Road Rash, EA 1991/1995）**
- 基础提示词覆盖：双向起伏弯道+压弯倾角、J/K/L 格斗系统（AI 车手挑衅、受击硬直、连击摔车）、撞车甩出滑行、90 年代街机 HUD（速度表/血条/排名）
- 步骤 5 时耗时 55 分 43 秒，任务完全不跑偏——上下文处理能力过硬
- Qoder 自己打开 Chrome 自测，发现建模粗糙、行驶方向反了，继续自我迭代修复
- 支持中途"插话"（插入当前上下文）或"插队"（插到队列头部）补充指令
- 未授权 Computer Use 时，自动降级 Chrome Use 完成游戏测试：用真实键盘事件（Enter 发车、W 油门、A/D 转向、J/K 出拳——与物理键盘同一输入通道）完整打一把，上下文级录像 + ffmpeg 转 mp4

### 3. 通用 Work 模式

- 两种模式：编程 / 通用 Work（更像一个 Worker，面向所有人）
- 能力组件：Goal（围绕明确目标持续工作）、Plan（先想清楚路径）、记忆+本地项目+运行状态（背景信息）、Browser Use / Computer Use
- 生态：40+ 连接器、70+ 插件、20K+ 技能，直接打通工作系统
- **实测三：视频制作**——`按照 ergo-remotion-video skill 为这期脚本 what-is-prefix-caching.md 制作`，一章工具执行 30+ 次，配音分片、五章逐一产出，全程零错误，自动开 Chrome 演示含声音

### 4. 价格

- 【经济】模式目前完全免费，不扣 Credits（个人订阅/Teams/企业版均可切换）
- 9 月活动：首单 Pro / Pro+ 加赠等额 Credits（Pro 首月 4000 / Pro+ 首月 12000）

## 关键洞察

- Harness 已成竞争主战场——模型能力趋同后，同 Harness 同提示词的实际产出对比才是真差异
- BYOK + 20K+ 技能生态 = 对 Claude Code / Codex 生态的正面进攻；开放模型中立正在成为 Agent 产品的护城河而非负担
- "经济模式免费"是激进的用户圈地策略，与首充赠 Credits 组合拳
- CU 权限未开时自动降级 Chrome Use——Agent 的权限降级容错是工程成熟度信号
- 一年前的 Qoder 是 IDE，现在的 Qoder 是 Worker：大厂正在把 Agent 从编程工具泛化为通用工作入口

## 战略分析

Qoder 的通用 Work 模式与 Hermes 这类个人 Agent 的定位正面重叠：Goal/Plan、记忆注入本地上下文、Browser/Computer Use、技能生态四件套全部齐备。对现有栈的启示：

1. **BYOK 值得跟进**：模型中立是长期护城河。Hermes 本身已是多 provider 架构（当前跑 zai/glm-5.3），但"用户自助接入任意 Key 零摩擦"的产品化程度可以对标 Qoder 的三步校验体验。
2. **20K+ 技能生态验证"skill 即分发"**：Qoder 接的是行业级技能市场，与 Hermes 技能体系方向一致；废才俱乐部的 Skill 工程实践与此趋势同频。
3. **"插话/插队"上下文注入**是长任务人机协作的好范式——Hermes 的 mid-turn steering 已有同构能力，但 Qoder 把它做成了显式 UI 交互，值得借鉴其可发现性设计。
4. **权限自动降级**（CU→Chrome Use）是 Agent 工程成熟度的信号，比硬失败体验好得多。
5. 大厂把 Agent 从 IDE 泛化到 Worker，验证了"Agent 承接日常工作"的判断；IDE 出身的 Qoder 反向吃通用 Agent 市场，与 chat 出身的通用 Agent 竞争会越来越胶着。
