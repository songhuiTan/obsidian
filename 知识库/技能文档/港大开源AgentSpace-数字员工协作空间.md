## AgentSpace 定位

港大 HKUDS 开源的 **面向"人类 + Agent"的共享工作空间**。

类比：
- Notion = 人的知识协作空间
- Slack/飞书 = 人的沟通协作空间
- Jira = 人的项目协作空间
- **AgentSpace = 人和 Agent 一起工作的协作空间**

它不是又一个单点 Agent 框架（如 LangChain），而是**协作层、管理层、治理层**。

> 单个 Agent = 能力很强的实习生
> Agent 框架 = 教它做事的方法论
> AgentSpace = 公司的部门系统 + 权限系统 + 任务系统 + 汇报系统

## 今天 Agent 工作流卡在哪

| 问题 | 表现 |
|------|------|
| **太私有** | Agent 跑在个人账号/电脑/API Key，团队不知道它做过什么 |
| **太分散** | 调研 Agent 在一个平台，代码在另一个，只能靠复制粘贴串联 |
| **缺协作层** | 复杂任务仍需人类在中间反复转手 |
| **缺治理** | Agent 越强，风险越大——无权限/无审批/无审计 |

## 四个核心能力

### ① 调度（AgentRouter）
根据任务类型，把任务分配给合适的 Agent。

例："分析近三个月用户反馈并生成改进建议"
```
资料 Agent 收集反馈 → 数据 Agent 分类统计 → 分析 Agent 提炼问题 → 写作 Agent 输出报告 → 人类负责人审核
```

### ② 能力共享
Agent 能力沉淀为**团队资产**，而非个人私有。
- 内容团队：选题 Agent / 资料 Agent / 标题 Agent / 初稿 Agent / 校对 Agent / 分发 Agent
- 研发团队：需求分析 Agent / 代码 Agent / 测试 Agent / 文档 Agent

### ③ 多 Agent 协作（War Room）
多 Agent 不是"让几个机器人聊天"，而是围绕**同一任务**分工协作：
- 谁接了什么任务？做到哪步？中间产物在哪？人类何时介入？失败如何重试？

AgentSpace 的 **War Room** 概念——任务作战室。

### ④ 安全治理
| 操作 | 策略 |
|------|------|
| 查公开网页 | 自动执行 ✅ |
| 读取内部文档 | 需要授权 🔒 |
| 发送外部邮件 | 人工确认 👤 |
| 修改线上数据库 | 禁止 / 走审批 🚫 |
| 使用客户隐私数据 | 留下审计记录 📋 |

## 内容团队可借鉴的实践

不用等 AgentSpace 成熟，现在就可以按"数字员工团队"改造工作流。

**内容生产最小 AI 分工系统：**
1. **选题 Agent**：抓取行业热点，输出 10 个选题
2. **调研 Agent**：整理资料、链接和核心观点
3. **结构 Agent**：资料变成大纲
4. **写作 Agent**：根据账号风格生成初稿
5. **校对 Agent**：检查事实、语气、错别字
6. **分发 Agent**：朋友圈文案、小红书标题、视频脚本

可用飞书/Notion/Dify/Coze/n8n 组合出简化版。

## 总结

Agent 的下一站，不是更会聊天，而是**更像一个可治理的团队成员**。

要有身份、有职责、有边界、有记录、有审批，也要能和其他 Agent 配合完成复杂任务。

> 未来会用 AI 的人很多，但能管理一支"AI 数字员工队伍"的人，才会真正拉开差距。
