## 视频概述

演示如何在 Claude Code 中利用 loop 循环实现全程自动化的开发流程。核心思路：通过循环让 AI 先创建文档文件并命名，约定好提示词，轮询检查文档是否写完，写完后自动进入 goal 模式完成开发目标。

## 核心工作流

1. **创建循环** — 让 AI 先创建文档文件并命名
2. **约定提示词** — 提示词分为两段：
   - 第一段：轮询文档是否写完
   - 第二段：注入 goal 模式编排
3. **检查完成** — 循环检查文档状态
4. **进入开发** — 文档写完后，自动进入正式开发过程，使用 goal 模式完成目标
   - 包含检查项和 Codex review 等

## 关键细节

- loop 里基本都是调用子 agent，**主 agent 负责编排**，避免上下文过长导致注意力涣散
- 使用 `/statusline` 命令调出模型名称、项目、分支、context 等信息
- 评论区讨论：多 agent（规划/开发/测试）通过内部线程传递消息也算 loop 模式
