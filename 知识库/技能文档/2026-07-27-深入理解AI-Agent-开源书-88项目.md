## 概述

一本将 Agent 从概念拉回工程现场的开源书籍（李博杰 著）。全书围绕一个朴素公式展开——**Agent = LLM + 上下文 + 工具**——用 **10 章**把 AI Agent 从原理讲到工程实战，配套 **95 个实验**全部开源（含本地项目与外部复现轨道）。

**仓库状态（2026-08-01 核对）：** 28.8K⭐ / 3K forks / Apache-2.0 / 13 种语言（中/英/西/印尼/阿/繁中/俄/泰米尔/越/日/土/韩/匈）/ 3 个 release（最新 v1.4）/ 1285 commits / 47 contributors。

## 运行配套实验

```bash
# 推荐：uv 锁文件可复现章节环境
uv sync --locked --extra ch1

# 或 pip
python -m pip install -e ".[ch1]"

# 运行实验
uv run python chapter1/context/main.py
```

- 统一支持 Python 3.10+（部分浏览器/记忆实验需 3.11+，第 8 章部分需 3.12+）
- 需要模型 API Key（支持 Kimi / 智谱 GLM / SiliconFlow / DeepSeek / Krill AI / OpenRouter）
- 克隆或安装源码 ≠ 实验完成，执行状态单独记录在 `docs/EXPERIMENT_STATUS.md`

## 关键洞察

- **不赶时髦。** 没有一上来就堆"多智能体编排、反思循环"等框架名，而是从"上下文加工具"这条最基础的链路开始
- **95 个实验不是 95 个一键启动 Demo。** 部分评测、训练和机器人实验依赖外部仓库、额外环境甚至真实硬件；API Key、依赖版本、模型费用仍然是"脏活"
- **工程现场大于概念。** 工具章节直接给了感知工具、执行工具和主动工具发现的实现；评估章节放了延迟压测和成本分析
- 仓库非常活跃：每天都有新 commit（2026-08-01 当日更新了 ch9 MiniCPM-o 实验、ch10 LLM 狼人杀模拟器）

## 战略分析

这本书的定位——**从概念到工程现场**——与当前知识库中大量"架构图堆叠"的 Agent 教程形成鲜明对比。它是一个系统化的补充资源：

| 维度 | 本书 | 当前知识库 |
|------|------|-----------|
| 配套代码 | 95 实验，含本地项目与外部复现轨道 | 技能文档为主，代码以 GitHub 存档形式 |
| 内容范围 | 全链路：上下文→工具→评估→训练→多 Agent | 点状深入（每篇讲一个具体工具或框架） |
| 工程粒度 | 延迟压测、成本分析、主动工具发现 | 架构拆解、配置说明 |
| 学习路径 | 从前几章开始，边读边跑实验 | 按需求快速定位 |

### 建议用法

**不要一口气啃完**，从前几章开始，先接通过"上下文加工具"这条链路，有实验跑通了再去啃后面的高级章节。

当前知识库已经覆盖了书中讨论的多个领域（MCP、记忆系统、Agent Harness、工具调用等），这本书可以作为一个系统化的**索引和导航**——先读对应章节建立全貌，再回到知识库找点状深入的具体文章。
