# 我的开源AI运维项目被人卖200块入群费，我选择帮他修bug

> 有人把我写了半年的开源AI运维平台拿来收费。我不生气，也不打算投诉。就两个要求：卖之前自己先跑通别骗钱，别说是你写的。甚至你卖的过程中碰到bug搞不定，来找我，我免费帮你修。

## 事件背景

作者（譚策）花了半年业余时间开发的 **ITOps Agent Platform**（AI运维多Agent自动化平台），在 GitHub 上完全开源免费。最近有粉丝告知，有人将该项目包装成"企业级AI运维平台"挂出来售卖，安装费几百到几千不等，还有 200 元入群门槛。

卖家直接复制了作者 README 里的内容（包括笔误），收取费用提供服务。

## 作者的态度

**第一反应不是生气，而是觉得"这东西真的有用"。** 有人愿意拿它去卖钱，说明项目有价值。比 GitHub 星星更能验证方向做对了。

### 两条底线（不投诉，但有要求）

1. **卖之前自己先跑通** — 拿了代码就去卖，收了钱又搞不定买家的问题，会损坏项目口碑。作者在 GitHub 上花了大量时间写文档、修 bug、回 issue，不想被投机者把口碑搭进去。
2. **保留出处，别说是你写的** — 可以说提供"安装部署服务"、"配置对接"，但不能说"这个系统是我开发的"。

### 更惊人的态度

> "如果你搞不定，欢迎你来找我。遇到bug、遇到你解决不了的问题，我免费帮你修。"

甚至愿意帮卖他项目的人修 bug。

## 项目速览

- **项目定位**：让 AI 去干运维那些重复性的脏活累活
- **核心能力**：告警来了，Agent 自己查日志、自己分析根因、直接甩结论（如"磁盘使用率92%，建议清理 /var/log"）
- **开源地址**：
  - GitHub：https://github.com/qinshihu/itops-agent-platform
  - Gitee：https://gitee.com/IT_Oline/itops-agent-platform
  - GitCode：https://gitcode.com/gcw_IM7aAihp/itops-agent-platform
- **在线演示**：https://agentdemo-0mwug01t6.maozi.io/
- **文档中心**：https://aiopsdoc-0mwug01t6.maozi.io/
- **教学书籍**：https://aiopsdoc-0mwug01t6.maozi.io/book/
- **项目官网**：https://www.zjzwfw.cloud/ITOpsAgentinfo

## 作者的视角

做这个项目的初心从来不是为了利益。就是想趁着 AI 这股东风，真正把 AI 落地到运维的真实场景里，把大家从繁琐、重复、没意义的体力活里解放出来。

文中有一段"钓鱼比喻"很生动：钓鱼的人不会按成本算（直接去菜市场买鱼更便宜），他要的就是那个漂动的瞬间、那个手感。做开源也是这样——享受的是过程，是看着自己写的代码真的能帮到人的那种成就感。
