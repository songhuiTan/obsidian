> 归档：2026-07-02

## 一、核心概念

### AI Coding 自动驾驶分级（L0-L5）

| 等级 | 名称 | AI Coding 定义 |
|------|------|---------------|
| L0 | 全手动 | 完全由人完成 |
| L1 | 代码补全与辅助 | AI 辅助补全代码片段 |
| L2 | 部分自动生成 | AI 生成函数/类/模块 |
| L3 | 有条件自动化 | AI 生成可运行代码并测试，阻塞时人工介入 |
| L4 | 高度自动化 | AI 承担大部分编码/测试/集成/交付 |
| L5 | 完全自动化 | 需求到上线全程 AI 完成 |

**去哪儿 2026 H1 目标：L3 自动化任务占比 30%+**

### Harness（驾驭/束带）——AI 研发过程控制能力

决定 AI Coding 上限的不是模型，而是 Harness。核心"四把锁"：

1. **AI 触发机制** — 在关键环节引入 Skills/Workflow/Agent
2. **约束与门禁** — 输入模板、编码规范、质量标准、准入条件
3. **安全隔离环境** — 沙箱/虚拟环境避免直接影响生产
4. **人工审查节点** — 需求/设计/合入/灰度/发布保留人工确认权

## 二、度量体系

### AI R&D Metrics = Volume × Maturity

**量**：出码率、出码量、团队覆盖率、需求覆盖率
**质**：Coding 自动化水平（L1-L3）、Harness 等级

### 自动化水平三维度（T/M/C）

- **T（绝对时长）** — 最早开始到最晚结束跨度，越小越好
- **M（用户消息数）** — 交互次数，越小越好
- **C（用户输入字符数）** — 需求表达精炼度，越小越好

### 双估时机制

- **原始估时**：不用 AI 时人工完成需求的 pd
- **AI 结合估时**：用 AI 后预计需要的 pd
- **AI 估时压缩率** = (原始估时 - AI 结合估时) / 原始估时
- **AI 估时兑现率** = (原始估时 - 实际工时) / (原始估时 - AI 结合估时)

## 三、核心平台

### QunarDevCenter — AI Coding 数据采集与代理管理

- 采集 Claude Code/Codex/Cursor/Copilot/OpenCode 的 Session 数据
- 本地过滤上报，仅上传公司 GitLab 相关会话（安全合规）
- 统一管理 CLI 端代理和模型配置
- 三张核心表：`session_upload_objects` / `session_meta_info` / `ai_gen_code_change`
- 出码率计算：基于 Git Blame + tag 间 diff + AI session 关联

### 天弦（QDO）— 研发自动化编排平台

- 一句话需求、异常修复、Workflow 需求、JDK 升级等场景
- 11 步传统流程压缩为分钟~小时级
- AI Agent 自动编码 → 编译修复 → git push → 部署 → 测试 → 交付
- 自修复闭环：编译/部署/测试失败后自动分析原因并重试
- Skills 市场：50+ Skills、4 个 Domain

**JDK 自动升级案例**：211 个应用成功升级，编译通过率 93%

### Qsuperpowers — 复杂业务需求开发框架

针对 2pd+ 复杂需求，把需求澄清、任务拆解、AI 编码、部署测试收敛为企业级流程。

**四大定制化方向**：飞书文档集成、AST 集成、CI/CD 集成、灭霸测试集成

**典型案例**：3pd 复杂需求（涉及 3 个系统、8 个任务）→ AI 1pd 完成，无 bug 上线，提效 66%

### Skills 沉淀与治理

- 从"个人经验"到"组织资产"
- 私有仓库验证 → PR → 基础研发团队审核 → 合并 → Gateway 统一分发
- Skills Gateway + 种子上下文注入
- 50 个 Skills、4 个 Domain、2 个主干能力

## 五、核心启示

1. **AI Coding 不是工具问题，是研发范式问题** — 重点是重新设计度量、流程、平台、治理
2. **Harness 决定上限** — 没有约束的高出码率是定时炸弹
3. **个人经验→组织资产** — Skills 治理是关键
4. **价值衡量进入计划阶段** — 双估时机制让 AI 提效可量化
5. **组织学习速度是护城河** — 研发系统是否能跟上 AI 进化速度

> AI Coding 的上限，取决于研发系统是否为 AI 重新设计。
