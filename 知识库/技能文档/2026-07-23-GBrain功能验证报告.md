### 2️⃣ gbrain think — 合成问答 + 缺口分析

```
用法: gbrain think "<问题>"
```

| 测试场景 | 结果 |
|---------|------|
| "Hermes Agent 的 OPC 架构是什么？" | ✅ 综合4篇资料，输出带引用的完整答案 + **Gap分析**（指出缺少角色间交互协议的细节） |

## 三、使用指南

### 日常用法（CLI）

```bash
# 检索知识库（最快，免费）
gbrain search "Agent 记忆系统"

# 合成问答（消耗少量 Token）
gbrain think "我对某公司的了解"

# 随手记录想法
gbrain capture "今天学到的新东西"

# 查看健康状况
gbrain doctor

# 重新索引
cd /Users/mac/Documents/workplace/obsidian/知识库/ && gbrain import .
```

### 在 Hermes 中使用（重启后）

配置已就绪，重启 Hermes 后可直接在对话中说：

> "帮我搜下知识库里关于 xxx 的内容" → 触发 `gbrain search`
> "综合我知识库里的资料，告诉我关于 xxx 的信息" → 触发 `gbrain think`
