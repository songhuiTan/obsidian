## 概述

**ApiGo**（原 crabc-api）是一款低代码 API 接口开发平台、企业级接口管理与数据服务平台。深度整合 SpringBoot + MyBatis 实现动态数据源和动态 SQL，在线可视化编写 SQL 后即可快速生成 API 接口对外提供服务。

核心价值：**数据库转 API，减少通用接口的 SQL 编写，让开发人员专注更复杂的业务逻辑。**

## 核心能力

### 数据库接入

支持多种 SQL/NoSQL 数据源：

| 类型 | 数据库 |
|------|--------|
| SQL | MySQL、Oracle、PostgreSQL、SQLServer、达梦、TiDB |
| NoSQL | ES（Elasticsearch）、Hive |

### 接口开发

- 可视化编写 SQL，快速发布为 API 接口
- 支持多 SQL 同时执行
- MyBatis 标签语法（动态 SQL、动态标签）
- 函数和存储过程调用
- 接口一键上下线

### 企业级功能

| 功能 | 说明 |
|------|------|
| 数据脱敏 | 敏感字段自动处理 |
| 数据转换 | 结果格式转换 |
| 国密加密 | 国产密码算法支持 |
| 协同开发 | 多团队协作 |
| 接口编排 | 多个接口组合编排 |
| 鉴权认证 | AppKey 认证、签名认证 |
| 限流熔断 | 接口限流控制、熔断保护 |
| 监控告警 | 调用指标统计 |
| 统一日志 | 请求日志管理 |
| 代理转发 | 第三方接口接入 |
| 微服务网关 | 集成支持 |

### 社区版功能

- **工作台**：可视化 SQL → API，支持多 SQL 并行、Mybatis 标签
- **数据源**：数据源列表 + 数据查询
- **应用凭证**：AppKey/签名认证 + 在线授权
- **接口列表**：上下线管理、限流控制
- **接口文档**：在线文档 + 在线测试
- **指标统计**：接口调用指标
- **接口日志**：调用日志 + 请求详情

## 战略分析

### 与现有体系的对照

| 维度 | ApiGo | 当前体系相关工具 |
|------|-------|----------------|
| 定位 | 低代码 API 开发平台 | — |
| 核心 | 数据库转 API | — |
| 数据源 | 8 种 SQL/NoSQL | — |
| 企业功能 | 鉴权/限流/熔断/监控/国密 | — |
| 部署 | SpringBoot 单体 + 前端静态页 | — |

### 应用价值

1. **API 快速交付**：对于数据库已有的业务数据，可视化 SQL → API 可以大幅减少 CRUD 接口的重复开发。特别适合内部数据服务、报表接口等场景。

2. **与 Hermes Agent 的协同**：Hermes 通过 HTTP API 调用外部工具，如果企业用 ApiGo 快速暴露数据接口，Hermes 可以调用这些接口获得实时业务数据。ApiGo 可以成为 Agent 的"数据服务层"。

3. **8 种数据源接入**：达梦、TiDB 等国产数据库支持，对企业国产化改造场景有价值。

4. **国密加密**：满足国内等保合规要求。

### 局限

- 本质是数据库 CRUD 能力外放，复杂业务逻辑仍需要传统开发
- 需要 Java/SpringBoot 技术栈部署运维
