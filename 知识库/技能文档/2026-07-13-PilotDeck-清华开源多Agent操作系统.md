## 简介

PilotDeck 由 **清华大学 THUNLP 实验室、面壁智能、OpenBMB 与 AI9stars** 联合研发并开源，面向通用场景、适用于多任务。核心理念：**一个人，一个 PilotDeck，一支智能体军队。**

每个项目有一个**独立工作舱 WorkSpace**——不只是 IDE 里的文件夹，而是一个完整的智能体生存环境。

---

## WorkSpace 核心特性

| 组件 | 说明 |
|------|------|
| **专属文件系统** | 每个项目可操作的文件范围清晰划定，AI 生成文件自动标识 |
| **专属记忆（Project Memory）** | 记住项目目标、进度、限制；Feedback Memory 记住你的偏好和要求 |
| **专属技能** | 技能商店一键安装到对应 WorkSpace，随任务增长自动沉淀能力 |

---

## 四大核心能力

### ① Always-on：你睡了，它还在干活
Agent **主动发现值得做的事**，自己干，干完落地成文件，等你来看。

**示例：** 睡前说"把这期播客翻译成英/日/韩/法/德/西/葡/阿拉伯/俄语，注意文化适配"。
- 自动拆分任务 → 调度子 Agent 并行执行
- 智能路由：简单语种走便宜模型，需要文化意译走强模型
- 早上 9 个翻译版本整整齐齐在 WorkSpace 里，费用不到一杯星巴克
- 实测用 20B 级别模型跑出很不错的效果

### ② Dream 模式（梦境）
Agent 在空闲时段自动回顾、整理和优化自身记忆，就像人类睡眠中整理白天记忆。
- 哪些经验值得沉淀
- 哪些记忆可压缩
- 哪些任务进度需要更新

### ③ 智能路由：简单任务不配用最贵的模型
自动判断任务复杂度分配模型层级：

| 任务类型 | 模型策略 |
|----------|---------|
| 简单（文案生成、格式调整） | 便宜模型，省 70%~90% |
| 中等（邮件撰写、数据分析） | 中等模型 |
| 复杂（策略规划、深度研究） | 强模型 |

**实测数据：**
- 小红书种草文案：**省约 70%**
- 复杂任务（播客多语言/论文综述/金融分析）：**1/6 成本**，效果超 Claude Sonnet 4.6 单 Agent

每个 WorkSpace 独立算账，每一分钱有去处。

### ④ 白盒记忆
AI 记错了？打开它的脑子直接改。
- 打开某项目的 WorkSpace → 直接查看 & 编辑 Memory
- **Feedback Memory** 记录每次纠正的偏好，越用越懂你
- 三个月后像磨合十年的搭档，说半句话就知道你要什么
- 专注 **Project Memory + Feedback Memory**，不把流水账对话转记忆

## 评价

**亮点：**
- 清华系团队出品，学术+工程背景扎实
- WorkSpace 隔离设计适合多项目管理（小红书/抖音/公众号/B站/X 并行运营）
- 智能路由省钱（70%~90%）有实测数据支撑
- 白盒记忆可编辑，不是黑盒
- Dream 模式做记忆整理是个有趣的设计

**潜在不足：**
- 刚开源，社区和生态还在早期
- 需要自己配模型，对新手有门槛
