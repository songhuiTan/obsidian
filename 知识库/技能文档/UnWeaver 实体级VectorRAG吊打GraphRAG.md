# UnWeaver — 不用建知识图谱，VectorRAG 就能吊打 GraphRAG

> 三星 AI 中心华沙团队提出 UnWeaver 框架：不建显式知识图谱、不用图数据库，仅在传统 VectorRAG 基础上增加轻量实体索引，就在多个权威基准上事实正确性全面领先 GraphRAG，同时索引阶段 LLM Token 消耗仅为 GraphRAG 的 1/10~1/17。

**论文:** https://arxiv.org/pdf/2603.29875

---

## 背景：RAG 的两难困境

### VectorRAG 的缺陷
- 粗粒度分块 → 一个 chunk 混合多个主题/实体，向量表示被无关内容稀释
- 检索噪声大，召回的 chunk 含大量无关内容 → 易引发 LLM 幻觉
- 多跳问答能力拉胯：关键信息分散在不同 chunk，纯向量相似度无法同时精准召回

### GraphRAG 的缺陷
- 索引阶段：实体识别、关系提取、实体链接、本体对齐、社区发现、集群摘要等十余个复杂步骤
- 检索阶段：无法复用 ANN 向量搜索，需定制图查询算法甚至专用图数据库
- 投入极高，效果却往往不如最基础的 VectorRAG
- 论文实验显示：GraphRAG 在多个基准上的事实正确性甚至不如 VectorRAG

## UnWeaver 核心架构

**设计哲学：不建图，只抓实体。** 没有建模实体间复杂关系，而是把核心精力放在「从 chunk 中拆解实体，聚合跨 chunk 的实体信息」。

### 阶段 1：离线索引

只比传统 VectorRAG 多了轻量实体处理：

```
文档分块 → 实体提取（LLM 对每个 chunk 提取实体+描述）
    → 实体聚合（同名归并，拼接跨 chunk 的描述）
    → 双索引构建：实体向量库 + 实体-chunk 二进制映射矩阵
```

**关键创新：** 同一实体的信息可能分散在数十个 chunk 里，聚合后的描述能完整还原实体全貌，嵌入向量放大核心信息、过滤无关噪声。

### 阶段 2：在线查询

全程纯向量检索，零图操作：

```
用户查询 → 向量嵌入 → 实体向量库 Top-K 搜索
    → 通过映射矩阵获取关联的原始 chunk（投票机制筛选 Top-N）
    → 作为上下文喂给 LLM
```

查询延迟与纯 VectorRAG 几乎无差别。

## 实验结果

### 事实正确性对比

| 数据集 | UnWeaver | VectorRAG | RAPTOR | GraphRAG |
|--------|----------|-----------|--------|----------|
| COVID-QA | **0.3823** | 0.3790 | 0.3643 | 0.3092 |
| eManual | **0.4811** | 0.4793 | 0.4466 | 0.3424 |
| Tech-QA | 0.3135 | **0.3218** | — | 0.2847 |

### 成本对比（索引阶段 LLM Token 消耗）

| 数据集 | UnWeaver | GraphRAG | 倍数 |
|--------|----------|----------|------|
| COVID-QA | 1,466k | 25,882k | **17.6x** |
| eManual | 98k | 1,428k | **14.5x** |
| Tech-QA | 3,747k | 49,270k | **13.1x** |

### 三个颠覆性结论

1. **效果全面领先**：COVID-QA 和 eManual 上事实正确性第一，远超 GraphRAG
2. **成本断崖式下降**：索引阶段 GraphRAG 消耗是 UnWeaver 的 13~17 倍
3. **查询效率拉满**：查询阶段 Token 消耗与纯 VectorRAG 同一水平，远低于 GraphRAG 和 RAPTOR

## 行业启示

> **GraphRAG 带来的核心价值，从来都不是「图结构」，而是「实体级的细粒度信息拆解」.**

1. **大道至简**：RAG 的核心是精准匹配，不是架构堆砌。抓住实体这个核心锚点，就能实现质的飞跃
2. **工程落地优先**：UnWeaver 完全兼容现有 VectorRAG 技术栈，增加一个实体提取步骤即可
3. **可解释性**：检索结果完全可解释——能明确知道是哪些核心实体召回了 chunk，这对金融/法律/医疗等高合规场景至关重要

## 与 Hermes 的关联

UnWeaver 的思路可以直接指导我们做知识库 RAG 的优化：
- 实体级拆解的思路，可以应用于 Hermes 的记忆/知识检索管线
- 如果当前用的是纯 VectorRAG，可以在索引阶段增加轻量实体提取来大幅提升效果
- 对比 WeKnora（腾讯 Go RAG）的父子分块策略，UnWeaver 是另一种更轻量的路线
