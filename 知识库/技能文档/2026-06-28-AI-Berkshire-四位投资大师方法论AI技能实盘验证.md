## 一句话

**AI Berkshire** 将巴菲特、芒格、段永平、李录四位价值投资大师的方法论编码为 18 个 AI 技能，通过多 Agent 并行研究输出带具体价格区间和仓位建议的投研报告，2024 实盘 +69.29%、2025 至今 +66.38%。

---

## 架构设计

```
Skill 层 (18 skills) → Agent 层 (4 独立 Agent) → 工具层 (A股数据/财报/搜索)
```

核心工作流：终端输入 `/investment-team 腾讯` → 同时启动四个独立 Agent：

| Agent | 视角 | 方法论来源 |
|-------|------|-----------|
| 商业模式 Agent | 商业本质分析 | 段永平 |
| 护城河 & 估值 Agent | 竞争壁垒与定价 | 巴菲特 |
| 逆向思考 Agent | 风险与死亡检验 | 芒格 |
| 长期确定性 Agent | 十年维度判断 | 李录 |

四个 Agent 各自搜索资料、交叉验证数据、独立打分，最后合成完整投研报告，含价格区间、仓位建议、风险清单。

---

## 与普通 AI 投研的差异

| 维度 | 直接问 AI | AI Berkshire |
|------|-----------|-------------|
| 输出风格 | "一方面…另一方面…请自行判断" | 具体价格区间 + 仓位建议 + 理由 |
| 防骗机制 | 无 | 信息丰富度评级(A/B/C) + 芒格式逆向检验 + 8条否决红线 |
| 数据精度 | float 计算 | Python decimal + 多源交叉验证 + 单位对齐 |
| 确定性管理 | 伪确定性 | 标注"灰色地带"和"留白" |
| 决策输出 | 回避决策 | 激进/稳健/保守三套策略 |

## 工程亮点

- **双平台兼容**：同一套技能同时适配 Claude Code（skills）和 OpenAI Codex（codex-skills），安装脚本一键
- **零外部依赖**：内置 A 股数据工具，通过腾讯行情 + 东方财富财务接口，不需外网
- **持续迭代**：1166 次提交，最后 commit 9 小时前，几乎每日更新
- **实盘验证**：README 第一屏就是富途账户截图（未打码），2024 +69.29%，2025 +66.38%

## 项目定位分析

AI Berkshire 不只是个投研工具，它是一套完整的 **Agent + Skill 工程落地案例**：

- **多 Agent 并行**：不是把一份 prompt 拆四份，而是四个分析师各做全套研究再合稿
- **流程内置质检**：信息评级、逆向检验、否决清单、数据精度 — 这些是工程化的质量控制层
- **人机分工明确**：AI 当执行层（搜资料、算数据、出初稿），人当决策层（判断、调整、决策）

对 AI Agent 开发者而言，这个项目的参考价值不亚于其投资价值。
