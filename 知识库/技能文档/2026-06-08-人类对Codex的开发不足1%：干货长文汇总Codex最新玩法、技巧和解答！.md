![CAD 生成别墅模型 - 步骤1](../assets/2026-06-08-Codex玩法技巧/img_003.gif)

![CAD 生成别墅模型 - 步骤2](../assets/2026-06-08-Codex玩法技巧/img_004.gif)

这事现在很多人还觉得新鲜，但我估计用不了多久，建筑设计里某些环节的工作流就会被这类工具直接改写。

## 7. 逆向反推文生图提示词

这个玩法，我觉得是今天最有意思的一个，不是因为它多难，而是因为它的思维方式不一样。

大多数人复刻图片的方式是：发图给 AI，AI 猜一次提示词，生图，完事。

这个玩法不是。

它搭的是一个有测试、有反馈、有迭代的机制。

核心是两个子智能体：

- A：逆向提示词智能体。看图猜提示词。
- B：监督智能体。用 A 猜出的提示词生图，和原图找差异，把差异拆成可执行反馈，再喂回给 A。

A 猜一次，B 打一次分，A 再改。最多 5 轮，或者分数达到就停。

这很像 GAN 的逻辑，一个生成，一个判别。但这里的判别器不是数学函数，它会说人话：人物太小、文字层级没锁住、光环位置不对。每一条反馈都可以直接变成下一轮的约束。

在 Codex 里怎么用呢？

我把之前生成的权力与游戏海报图上传给 Codex，然后粘贴这段提示词：

> 创建两个子智能体，一个是逆向提示词智能体 A，一个是监督智能体 B。A 的作用是猜测一张图片背后的提示词。B 智能体负责用猜出来的提示词生图，对比和原始图片的差异，然后不断给 A 反馈，让它迭代提示词。终止条件：B 认为差距很小，或者达到第 5 轮迭代。

发完之后，Codex 启动了整个迭代流程，一共跑了五轮，耗时一个多小时。

![逆向提示词迭代流程](../assets/2026-06-08-Codex玩法技巧/img_014.gif)

第一轮，A 猜出大致风格：黑暗奇幻封面、火焰城堡、左侧文字区。B 生图看完说：氛围对了，但女性侧脸没抓到，徽章和文字层级都没锁住。

第二、三轮，A 陆续补进女性轮廓、纹章位置、燃烧城镇。B 每次指出新问题：女性偏右、脸朝向不对、火焰颜色太深。打分从 65% 爬到 75-80%。

第四、五轮，A 开始精修空间关系——女性左侧占 40%、哥特塔尖轮廓、徽章颜色细节、文字间距。B 最终评估：主要元素、氛围、构图都复现了，只有极细节光晕位置有偏差。最终相似度：91-93%。

迭代结束，最终提示词是这样的：

![最终提示词](../assets/2026-06-08-Codex玩法技巧/img_015.png)

我把反推出来的提示词再发给 Codex，生成了这样的结果。

![反推生成结果](../assets/2026-06-08-Codex玩法技巧/img_016.png)

我把生成的结果和原来的图片对比了一下，左边是原图、右边是新提示词生成的图。确实没有达到百分百复刻，但是这个思路是真的很棒。

![原图 vs 新生成对比](../assets/2026-06-08-Codex玩法技巧/img_017.jpg)

这个玩法它更像是一个可以借鉴的思路：以后很多需要反复试错的创作流程，都可以用这个思路改造，把「我猜一次」变成「AI 帮我迭代」。

# 几个用得上的技巧

其实第一部分已经足够一篇文章的分量了，但是最近这段时间 Codex 进化速度太快，除了上面玩法上的骚操作，还有一些实用上的小技巧，一并整理给大家。

## 1. 额度翻倍的方法

这个是从卡兹克留言区发现的。

确实很实用：

![额度翻倍方法](../assets/2026-06-08-Codex玩法技巧/img_018.png)

首先，要知道 Codex 的额度不是按天重置，也不是按小时重置。

是一个 5 小时的滚动窗口。

![滚动窗口说明](../assets/2026-06-08-Codex玩法技巧/img_019.png)

你发第一条消息的那一刻，计时开始。这 5 小时内 token 用完，就只能等窗口走完才能重置。

但有一个细节很多人不知道，窗口走完之后，系统不会自动开新窗口。

它就在那等着，等你下一条消息发出去，才重新开始计算 5 小时。

所以重置时间，是你自己控制的。

举个例子。你每天下午 2 点到 6 点集中用 Codex。如果 2 点开始，窗口 7 点才重置，3 点半额度用完，你就得干等到 7 点。

但如果你上午 11 点随手给 Codex 发一句话，哪怕就说「你好」，窗口从 11 点开始，下午 4 点就重置了。

2 点开始干，4 点额度刷新，4 点接着干。

同样 4 个小时，你享受了两个窗口。

这个也可以自动设置，在左边栏找到「自动化」，新建一个，触发条件选「每天」，时间填你开始干活的 3 小时前，动作就是随便发一条消息，写啥都行。设好之后不用管，每天自动跑。

## 2. 开启记忆功能

这个建议开，设置 → 个性化 → 记忆 → 启用记忆。

![开启记忆功能](../assets/2026-06-08-Codex玩法技巧/img_020.png)

开启之后，经过一段时间沉淀，你可以在 ~/.codex/memories 目录下找到 memory.md 文件，里面是 Codex 主动记录下来的关于你的信息，你的习惯、你的项目、你的偏好。

## 3. 长任务进行中，怎么查进度

有时候一个任务跑很久了，不知道跑到哪了，这时候可以用 /side 指令开一个 side chat。

不影响当前会话，但有当前会话的完整上下文。

比如这样问：

```
/side 目前进度如何了？预计还要多久？
```

![/side 查进度 - 指令](../assets/2026-06-08-Codex玩法技巧/img_021.png)

不打断任务，但能随时看状态。

![/side 查进度 - 结果](../assets/2026-06-08-Codex玩法技巧/img_022.png)

这个细节很实用。

## 4. 额度使用卡 bug

Codex 还是很厚道的，每次你跑一个 Goal 模式的任务，也就是追求目标模式的任务，即便你现在的额度已经只剩 1% 了，它也会完成任务给你交付结果。所以如果你这周的额度血槽快空了，这时候不妨跑一个规划完整的任务，榨干最后一滴。

需要注意的是，中途千万不要使用引导给它插话，一但它对你响应回复，就会弹出额度受限，这个任务就没法完成了。

# 疑难解答

还有一些使用时候的疑难问题，本来上次土区半价 Codex 教程里已经写过了，但是因为文章被和谐了，不少小伙伴没看到，这里就再补充一些目前依然有效的。

这些是在使用 Codex 过程中大家最容易踩的坑。

## 1. 微软应用商店卡死，怎么办？

这个是 Windows 用户的老毛病了，最大化窗口或者安装过程中特别容易卡住，大概率是缓存或者应用本身出了问题。

按顺序来试，哪招好使就停：

**第一招**：按 Win + R，输入 `wsreset.exe`，回车。黑窗闪一下就行，等个 10-20 秒，商店会自动重启，缓存清了，很多卡死直接就好了。

**第二招**：去设置 → 应用 → 已安装的应用，找到 Microsoft Store，点修复，不行再点重置。重置不会删东西，就是把配置清一清。

**第三招**：用管理员权限打开 PowerShell 跑修复命令，或者去下个微软商店的离线安装包升级版本，重启电脑再试。

另外，装 Codex 的时候建议别最大化窗口，先正常窗口大小操作。实在搞不定，换个网络或者开手机热点试试。

## 2. 下达指令后老是出现 Reconnecting？

这个简单，把魔法改成 tun 模式就行了。

## 3. 执行命令总是报错，磕磕绊绊跑不顺？

这个原因是 Codex 在 Windows 上默认走的是 PowerShell 5.1，很多命令和脚本语法跟 PowerShell 7 有差异，跑起来就容易出问题。

解决办法：升级到 PowerShell 7，能省掉很多麻烦。

用管理员权限打开 PowerShell，输入这条命令：

```
winget install --id Microsoft.PowerShell --source winget --accept-package-agreements --accept-source-agreements
```

装完关掉窗口，重新打开终端，输入 `pwsh` 启动新版，再跑 `$PSVersionTable` 确认一下，显示 7.6.x 就对了。

## 4. 插件入口里搜不到 Computer Use、Chrome 插件？

要知道，这两个功能要是废了，Codex 基本上就是自断一臂。因为一旦这两个开放，它就接管了你电脑上几乎所有操作，而且是可视化的、所见即所得的，你能真正看着它干活。那个感觉，是真的很爽。

![插件搜索不到](../assets/2026-06-08-Codex玩法技巧/img_025.png)

而且在插件里也搜索不到。

![插件界面](../assets/2026-06-08-Codex玩法技巧/img_026.png)

**第一个方法是用 Codex++。**

这个最近的文章也介绍过用法，专门修官方原版那些烦人的小问题，会话列表删不掉、API 模式进不去插件、插件入口被锁……这些它都能搞定。

自动解锁插件功能、加删除按钮、支持导出会话，装上之后省心很多。

**如果上边的解决不了，还可以试试下面这个方法：**

找不到这两个插件也有可能是 Windows 版 Codex 本地 bundled 插件源读取异常。

把下面这段提示词发给 Codex：

> 我现在使用的是 Windows 版 Codex 桌面端，Computer Use 插件无法正常使用。
>
> 请你帮我诊断并修复本机 Codex 的 openai-bundled 插件源问题。我的目标是让以下插件恢复正常
>
> chrome@openai-bundled
>
> computer-use@openai-bundled
>
> 请按下面要求操作:
>
> 1. 先只读检查，不要直接修改配置。
> 2. 检查 codex plugin marketplace list、codex plugin list, 以及 openai-bundled 插件源是否存在。
> 3. 检查 Codex 桌面版安装目录中是否存在 resources/plugins/openai-bundled。
> 4. 修复前必须备份 ~/.codex/plugins、~/.codex/config.toml、~/.codex/codex-global-state.json。
> 5. 不要修改 WindowsApps 目录权限，不要接管 WindowsApps 所有权。
> 6. 如果 openai-bundled 位于 WindowsApps 或类似受保护目录，请把 resources/plugins/openai-bundled 复制到用户目录下，例如 ~/.codex/openai-bundled-fixed。
> 7. 复制时尽量使用安全方式，避免 WindowsApps 权限导致 os error 6000。
> 8. 复制完成后，重新注册这个本地插件源。
> 9. 然后安装或启用 chrome@openai-bundled 和 computer-use@openai-bundled。
> 10. 最后运行 codex plugin list 和 codex plugin list --marketplace openai-bundled 验证结果。
>
> 请每一步都告诉我你要执行什么命令，以及这个命令的作用。不要删除整个 .codex 目录，不要重置我的的全部配置。

![修复提示词 - 发送](../assets/2026-06-08-Codex玩法技巧/img_027.png)

再根据 Codex 提示完全退出后重新打开，再去看插件已经安装好了。

![插件修复成功](../assets/2026-06-08-Codex玩法技巧/img_028.png)

关于这个方法，我已经在三台电脑上试过，最后都是由这个方法完美搞定。
