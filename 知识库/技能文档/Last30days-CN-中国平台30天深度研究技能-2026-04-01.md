## 一句话概括

30天的研究，30秒的结果。自动搜索8大中国平台最近30天内容，综合分析生成研究报告。

## 核心特性

- 🔍 **8大中国平台覆盖** — 微博、小红书、B站、知乎、抖音、微信公众号、百度搜索、今日头条
- 🤖 **多Agent兼容** — Cursor、Claude Code、OpenClaw、Gemini CLI
- 🇨🇳 **中文NLP** — jieba分词、中文停用词、同义词扩展
- 📊 **智能评分** — 相关性45% + 时效性25% + 互动度30%
- 🔄 **跨平台对比** — 自动关联多平台相同话题
- ⚡ **4个免费源** — B站、知乎、百度(基础)、头条无需API Key

## 平台支持

| 平台 | 模块 | 需要配置 |
|:---:|:---:|:---:|
| 🔴 微博 | weibo.py | WEIBO_ACCESS_TOKEN（可选） |
| 📕 小红书 | xiaohongshu.py | SCRAPECREATORS_API_KEY（可选） |
| 📺 B站 | bilibili.py | ✅ 无需 |
| 💬 知乎 | zhihu.py | ZHIHU_COOKIE（可选） |
| 🎵 抖音 | douyin.py | TIKHUB_API_KEY（可选） |
| 💚 微信 | wechat.py | WECHAT_API_KEY（可选） |
| 🔵 百度 | baidu.py | 基础免费；BAIDU_API_KEY（可选） |
| 📰 头条 | toutiao.py | ✅ 无需 |

## 使用方式

```bash
# 基本搜索
python scripts/last30days.py "AI编程助手" --emit compact

# 快速搜索（仅B站+知乎）
python scripts/last30days.py "Python教程" --quick --search bilibili,zhihu

# 深度搜索
python scripts/last30days.py "新能源汽车" --deep --save-dir ~/Documents/research

# JSON输出
python scripts/last30days.py "ChatGPT替代品" --emit json

# 最近7天
python scripts/last30days.py "热门话题" --days 7
```

### 命令行参数

| 参数 | 说明 | 示例 |
|:---:|:---:|:---:|
| --emit | 输出模式 | compact/json/md/context/path |
| --quick | 快速搜索 | 更少数据源 |
| --deep | 深度搜索 | 更多数据源 |
| --days N | 回溯天数 | --days 7 |
| --search | 指定搜索源 | --search weibo,bilibili,zhihu |
| --diagnose | 诊断配置 | 显示各平台可用状态 |
| --debug | 调试模式 | 详细日志 |

## 评分系统

- 🎯 相关性 45% — 与查询主题的文本匹配度
- 🕐 时效性 25% — 内容发布时间的新鲜程度
- 🔥 互动度 30% — 各平台互动指标
