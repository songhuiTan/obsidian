## 概述

Plane 是一款开源 AI 原生项目管理工具，对标 Jira / Asana / Linear。核心卖点是**把 AI 直接做进工作流**，支持自部署（完整功能），已获 SOC 2、ISO 27001、GDPR、CCPA 四项安全认证。

## 核心功能

### AI 原生工作流（三大能力）

| 能力 | 说明 |
|------|------|
| **Talk to build** | 说话建项目：描述需求 → AI 自动建好项目骨架、拆任务、排周期 |
| **Ask to know** | 自然语言查项目状态：「下周到期的任务里谁还没开始」→ 秒回 |
| **Assign to ship** | 在卡片中 @AI Agent，AI 自动读上下文、判断优先级、转派、加标签 |

### 问题跟踪与视图

- **Issue**：基本任务卡片，支持列表/看板/日历三种视图
- **Cycles**：固定冲刺周期，单活跃周期防烂尾，含燃尽图
- **Modules**：轻量模块打包，相关 issue 组合跟踪（类似 git submodule）
- **Views**：自定义过滤器，按优先级/状态/标签/负责人组合，可保存分享

### 键盘优先 & 集成

- 全局搜索 `Cmd+K`，新建 issue `C`，新建 cycle `Q`，几乎不用鼠标
- GitHub Sync：Plane ↔ GitHub issue 双向同步
- Slack 集成：频道收通知、slash command 创建 issue
- **MCP 服务器开源**：可接入 Claude / Cursor，把项目管理塞进 AI 开发环境

### 自部署

Docker Compose 一键启动（PostgreSQL + Redis），自部署版本与云版本功能完全一致，AI 能力也能用。承诺不存 prompt、不拿数据训练模型。提供 air-gapped 部署方案。

## 对比竞品

| 维度 | Jira | Asana | Linear | Plane |
|------|------|-------|--------|-------|

| AI 能力 | 插件后装 | 弱 | 摆设型 | 原生深度集成 |
| 视图灵活度 | 高 | 中 | 中 | 高（列表/看板/日历/自定义） |
| 键盘体验 | 一般 | 需鼠标 | 好 | 好（全流程快捷键） |
| 开源/自部署 | ❌ | ❌ | ❌ | ✅ 完整功能自部署 |

## 局限性

- 移动端（iOS/Android）刚出，功能不全
- 社区插件市场还没起来，目前仅 GitHub Sync + Slack 两个官方集成

## 关键评价

> 它的核心优势太明显：**AI 原生、键盘优先、开源、自部署完整功能**。如果你受够了 Jira 的笨重，又嫌 Asana 太简陋，还想让 AI 真正替你干活，Plane 值得你试。
