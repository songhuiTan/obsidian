## 视频要点（Whisper ASR 转录）

大厂做 Agent 落地的核心挑战分三类：

**1. 治理挑战**
- 大厂 Agent 落地的难点不是技术，是组织协调（跨团队、跨部门）
- 选内部高频场景做切入点，但责任归属要先明确
- 模型选择要做分层策略：简单任务用轻量模型，复杂任务用顶尖模型，中间加路由引擎

**2. 知识挑战**（最被低估）
- 知识碎片化：几十个部门、格式不统一、更新频率不一、文档陈旧
- 很多知识在员工脑子里不在文档里
- 核心做三件事：
  - 建立知识转入标准
  - 明确准入规则和定期清理
  - 知识显性化（FAQ 把脑子里的东西抽出来）
  - 知识评分（有用性、准确性、时效性 → 低分自动清理）
- 做完后准确率从 60% 提到 85%

**3. 工程挑战**
- **RAG 可观测性**：任何 Agent 代码必须有对应日志（输入/输出、边界条件、异常策略），加了之后 Bug 率降 40%
- **多 Agent 协作**：大厂审批流程复杂，自建轻量调度系统，每个 Agent 只负责明确职能，通过消息队列通信
- **数据安全**：内部数据分析、敏感数据不出内网，做数据网关统一管控
- **存量系统集成**：老系统没 API，用 RPA 做桥接
