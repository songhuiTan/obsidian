## 花生壳这一侧到底是什么（官方口径补充）

视频只用了一句话带过"上传至花生壳获取域名"，实际产品形态是**两个东西**：

### 1. 花生壳 Drop —— 静态文件发布

- 定位：拖文件/文件夹上去 → 拿到公网链接 → 7×24 在线，本地关机不影响
- **已备案域名，国内直开，微信里点链接能直接打开**（这是它相对 Cloudflare Pages / workers.dev 的核心优势——`workers.dev` 在国内很多网络打不开）
- 当前**完全免费**（有免费版，也可付费升级权益）
- ⚠️ **入口文件必须叫 `index.html`** —— 和 Cloudflare Drop / GitHub Pages / Vercel 的通用约定一致。AI 生成的文件如果叫 `home.html` / `main.html`，记得改名，否则打开是 404
- 控制台可把公网地址的**域名前缀改成自定义名字**，链接更好记

### 2. 花生壳 CLI（`@aweray/hsk-cli`）—— 给 Agent 用的那条路

视频 02:29 提到的 CLI 模式，官方设计目标很明确：**不是给人用的，是给 AI Agent 用的**。

- 两大能力：**静态文件托管**（`帮我把这个文件夹用花生壳 CLI 托管上线`）+ **内网穿透**（把本地 3000 端口映射到公网，不需要公网 IP、不需配路由器）
- 安装：`npm i -g @aweray/hsk-cli`，或直接让 Agent 读 `https://hsk.oray.com/doc/cli-setup.md` 自行安装
- 可写成**系统服务后台运行 + 开机自启**，设备重启后映射自动恢复
- 结果支持 **JSON 输出**，能塞进 GitHub Actions / Jenkins 等 CI 流程
- 支持 Windows / macOS / Linux

## 三个方案的横向定位（同一条链路的三种走法）

你现在手上有三份「AI 生成 → 上线 → 手机装」的归档，它们其实是**同一条链路的三种分发方案**：

| 方案 | 生成 | 托管 | URL/费用 | 适合 |
|---|---|---|---|---|
| **花生壳 Drop**（本篇） | WorkBuddy / 任意本地 AI | 花生壳（备案域名） | 免费、国内直开、**微信能打开** | 要发给国内的人看、零成本、不想注册一堆平台 |
| **StepPage**（第14集） | Step Code（终端 Agent） | 阶跃星辰 StepPage | 需 Step 账号，额度与模型套餐分开计 | 已经在用 Step Code、要版本 promote/rollback |
| **自建静态托管** | 任意 | Cloudflare Pages / Vercel | 免费额度大，但国内访问不稳 | 要长期、要自定义域名、要 CI/CD |

**生成层不用换**——你昨天那份 PWA 提示词三家通用。**分发层才需要选**。

## 要留意的四个坑

1. **`index.html` 命名**：静态托管通用硬性要求，AI 生成的工作台文件常被命名成中文名或 `home.html`，上传前必须改成 `index.html`
2. **iOS 的限制**：Safari "添加到主屏幕" 读不全 manifest 字段（图标、`display` 有时不生效），必须靠 `apple-mobile-web-app-capable` + `apple-touch-icon` 等 meta 兜底——这就是为什么你那份提示词第 3 条强调"必须自带专属高清 App 图标"
3. **安卓要 Chrome**：视频明说安卓需装谷歌浏览器才能"添加到桌面"。国产浏览器（UC/QQ/夸克）大多不支持完整 PWA 安装
4. **纯静态 = 无同步**：作者自己承认数据只能存本地。教学场景要注意——学生姓名、家长电话这类数据托管到公网静态站上，等于**有链接的人都能看到源码里的默认数据**，真实数据务必只存本地 localStorage，不要预置在 HTML 里
