# 开源 OpenClaw 本地可视化看板

> GitHub 项目：[openclaw-control-center](https://github.com/TianyiDataScience/openclaw-control-center)
> Stars：1.1k

平时跑 OpenClaw 智能体，如果想看看系统花了多少 Token、哪些任务卡住了，往往只能去翻原始的后端代码数据和终端日志，这对团队里的非技术人员或者运营同学来说门槛太高了。

GitHub 上有个由 TianyiDataScience 团队开源的 **OpenClaw Control Center** 专门解决这个问题。它是一个专为 OpenClaw 打造的安全优先、本地优先的控制中心（主要使用 TypeScript 开发）。

它提供了一个直观的中英双语监控面板，把复杂的系统运行状态翻译成了所有人都能"看得懂、看得准"的可视化数据，并且默认开启极高的安全防护，防止非技术人员误操作。

## 核心监控功能分区

控制中心主要分为以下几个直观的功能模块：

### 总览
作为主操作页，集中展示当前的系统总体态势、待处理事项、运行异常、预算风险等，用于快速回答"系统当前是否正常"这一问题。

### 用量
展示今日、7 天、30 天的 token 用量和花费趋势。近期版本新增了"上下文压力"指标，可直观看到哪些会话接近上下文上限，以此预警变慢或变贵的风险。

### 员工
实时监控智能体 (Agent) 的工作状态，明确区分谁在真正执行任务、谁处于排队待命状态，防止将积压任务误认为正在运行。

### 任务
将任务板、排期、审批、执行链和运行证据集中展示，帮助用户理解哪些是计划中的任务，哪些已有真实的执行证据，以及哪些任务卡住了需要介入。

### 文档与记忆
提供基于源文件的工作台。记忆工作台不仅能查看/编辑记忆，还会提示每个智能体的记忆是否正常、可搜索。文档和记忆的作用范围会严格跟随当前真正活跃的智能体。

### 设置
展示安全模式、连接状态等。最新版本加入了"接线状态"（提示哪些数据未接好）、"安全风险摘要"（将风险翻译成大白话）和"更新状态"面板。

## 安装部署与环境依赖

项目运行需要依赖已有的 OpenClaw 安装环境、可连接的 OpenClaw Gateway 以及 Node.js/npm 环境。

### AI 自动化接入（最推荐）
项目提供了一份名为 `INSTALL_PROMPT.md` 的安装指令文件。官方最推荐直接把这段指令发给你的 OpenClaw 智能体，让 AI 代劳完成环境检查、安装依赖、配置环境变量文件 `.env` 以及运行测试。

### 手动配置
用户也可以手动配置 `.env` 文件，定义 Gateway 地址、OpenClaw 主目录、Codex 数据目录及订阅快照文件路径等。

## 安全注意事项

项目秉持"首次接入默认安全"的原则，具备极强的防御性设计：

- **默认只读与鉴权**：系统默认处于只读模式（`READONLY_MODE=true`），且默认开启本地 token 鉴权（`LOCAL_TOKEN_AUTH_REQUIRED=true`）。
- **高风险操作限制**：导入、修改状态等高风险写操作默认关闭；审批动作默认关闭且默认开启 dry-run（试运行）模式。
- **API 保护**：所有修改型 API 都要求 `application/json` 格式，并需要通过 Header 传入本地 Token 鉴权。
- **非侵入性红线**：严格限制只修改控制中心自己目录（`control-center/`）内的文件，绝对不会擅自改写 OpenClaw 的核心配置文件（如 `~/.openclaw/openclaw.json`）。
