## 概述

**jzsub** 是一个视频下载工具：给一条链接，自动下载最高画质视频、封面、双语字幕，最后输出一个**烧录好字幕的 MP4 文件**。基于 yt-dlp，主打"一站式交付"。

## 主要功能

| 功能 | 说明 |
|------|------|
| **最高画质** | 下载最佳视频与音频，尽可能无损封装 MP4 |
| **按需交付** | `--deliver` 可选完整烧录 / 仅视频 / 仅原始字幕 / 双语字幕 |
| **双语字幕** | 紧凑分批翻译 + 批间上下文衔接 + 按句子边界重新切分；原文保持不变。默认译中文，`--target-lang` 可指定任意语言 |
| **自动烧录** | MiSans 字幕、底部双语堆叠、自适应竖屏、libass 渲染 |
| **低耗运行** | 只读取紧凑字幕文档，不读取完整清单；烧录每 5% 显示一次进度 |
| **封面直取** | 自动下载并转换为 `封面.jpg` |
| **静默登录** | 需要时直接读取 Chrome 登录态，不导出 Cookie |
| **无字幕兜底** | 平台没有字幕时直接交付视频、MP4 和封面 |

## 四种输出模式

| 模式 | 输出 |
|------|------|
| `full`（默认） | 视频 + 封面 + 字幕 + 烧录好的双语 MP4 |
| `video` | 只要视频和封面，不翻译不烧录（平台有字幕则保留原始字幕文件） |
| `subs` | 只要字幕，不下视频流 |
| `bilingual-subs` | 只要双语字幕文件（SRT/ASS），不下视频 |

**支持平台：** YouTube、B站、Vimeo、Twitch、Dailymotion、TikTok，以及 yt-dlp 能处理的其他站点。实际能下到什么格式、有没有字幕、要不要登录，取决于平台本身。

### 价值判断

1. **双语字幕 + 烧录是差异化卖点**：jzsub 不是又一个 yt-dlp 封装，它的核心增量在**字幕翻译流水线**——紧凑分批、上下文衔接、句子边界重切分，然后 libass 渲染烧录。这对学习场景（外语视频带中文字幕）和内容二次创作（双语字幕视频）都有实用价值。

2. **与刚装的 z-video-downloader 互补**：z-video-downloader 更全（支持视频号等平台、断点续传、批量清单），但无字幕处理；jzsub 字幕能力强。如果日常需要"下载+字幕"，jzsub 值得补装。

3. **`--deliver bilingual-subs` 模式**对 RAG/知识库场景有用——只拿双语字幕文件（SRT/ASS）不下载视频，可以直接作为文本语料进知识库。

### 局限

- 依赖 yt-dlp，平台风控/登录限制与 yt-dlp 生态一致
- 字幕翻译需要额外 LLM 调用（默认中文，可指定任意语言），有成本
- 竖屏自适应和烧录质量依赖 libass 渲染链
