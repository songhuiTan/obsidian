## 概述

Claude-tap 是一个本地代理 + Trace 查看器，一行命令就能拦截 Claude Code、Codex、Cursor、Gemini CLI 等 AI 编程工具的**全部 API 流量**，让 system prompt、工具调用、token 用量全部无所遁形。被称为 **"AI Agent 领域的 Wireshark"**。

## 安装

```bash
# uv 安装（推荐）
uv tool install claude-tap

# pip 安装
pip install claude-tap

# 升级
claude-tap update
```

## 使用方式

将原来的启动命令换成 claude-tap：

```bash
# 原来
claude

# 改成
claude-tap
```

其余使用方式完全不变，所有功能正常运行，只是现在能看到底层在发生什么。

## 核心功能

| 功能 | 说明 |
|------|------|
| **完整的 System Prompt** | 查看几千 token 的 system prompt，含工具规范/安全约束/动态注入信息 |
| **逐字符请求 Diff** | 对比相邻两次请求的上下文变化，定位"忘事"原因 |
| **Token 用量明细** | 输入/输出/缓存读取/缓存创建，精确分项 |
| **工具调用完整链路** | tool_use 请求 ↔ tool_result 全链路，含入参出参 |
| **实时查看器** | Agent 运行时自动打开浏览器，实时追踪每个 API 请求 |
| **HTML导出** | 退出时生成自包含 HTML 文件，零依赖离线可打开，可归档/分享 |

## 支持的客户端（12+）

| 客户端 | 启动方式 |
|--------|----------|
| Claude Code | `claude-tap` |
| Codex CLI | `claude-tap --tap-client codex` |
| Gemini CLI | `claude-tap --tap-client gemini` |
| Cursor CLI | `claude-tap --tap-client cursor` |
| Kimi Code CLI | `claude-tap --tap-client kimi-code` |
| OpenCode | `claude-tap --tap-client opencode` |

支持 DeepSeek API 代替 Anthropic API 的场景：

```bash
export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
claude-tap -- --permission-mode bypassPermissions
```

## 安全性

- 常见鉴权 header（Authorization、x-api-key 等）写入 trace 前自动脱敏
- 所有数据存本机，不上传云端，无需注册

## 适合人群

- **Claude Code / Cursor 重度用户**：排查 Agent 表现变差的根本原因
- **Prompt 工程**：看到完整 system prompt 和 token 分项，优化方向清晰
- **团队协作**：导出 HTML 文件共享，统一理解 Agent 行为
- **Agent 开发**：专用 AI API 语义调试代理，比通用 HTTP 抓包更懂 LLM 语义
