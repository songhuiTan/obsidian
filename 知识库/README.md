## 🔄 归档流程

微信文章 → `kb-archive-article` → 技能文档/
B站/YouTube/抖音视频 → `video-archiver` → 技能文档/ + assets/
飞书文档 → `feishu-doc` → 技能文档/

当前支持的归档方式：
- 📄 **微信文章** → `kb-archive-article` skill（自动下载图片）
- 🎬 **B站/YouTube/抖音视频** → `video-archiver` skill（元数据 + whisper 转录）
- 📝 **飞书文档** → `feishu-doc` 工具
