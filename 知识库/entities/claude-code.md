# Claude Code

## 概述

Claude Code 是 Anthropic 出品的终端 Agent 编程工具，通过 Terminal 与 Claude 模型交互，实现代码生成、编辑、调试、项目构建等开发任务。它采用 **Loop 工程模式**（规划-执行-验证循环），支持动态工作流、Skill 系统和 Harness 集成。

Claude Code 的核心优势在于与 Claude 模型的深度集成、强大的代码理解和生成能力，以及丰富的 Skill 生态。它代表了"Agent 作为编程助手"这一范式的最前沿实践。
