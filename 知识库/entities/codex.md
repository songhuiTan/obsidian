# CodeX / Codex

## 概述

CodeX（也称 Codex）是终端 AI 编程 Agent 工具，专注于通过命令行界面辅助软件开发。与 Claude Code 类似但生态更开放，Codex 强调 **Skill 系统** 和 **Prompt Canvas** 等创新交互方式。

Codex 的特色包括：5 Skills 指北师体系、Prompt Canvas 无限画布、免费开源原型 Skill 生态等。社区评价认为"人类对 Codex 的开发不足 1%"，意味着巨大的扩展潜力空间。
